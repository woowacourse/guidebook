# /말투점검

큐레이션 교육 문서(`content/education` 의 philosophy·insights·design-patterns·curriculum·tools)의 본문 말투를 점검한다. 규약: 본문은 **합니다체**로 통일하며 한다체·해요체를 섞지 않는다. (상세: `AGENTS.md` > 기여 규약 > 6. 문체)

## 실행

```bash
npm run lint:tone
# 또는
node scripts/style/tone-lint.mjs
```

## 동작

`scripts/style/tone-lint.mjs` 가 다음을 수행한다:

1. 범위 파일에서 코드블록·인라인 코드·frontmatter·마크다운 링크·`tone-lint:ignore` 블록을 제외한 **본문**만 검사한다.
2. 문장 끝의 한다체(`~다`, 단 합니다체 `~니다` 제외)·해요체(`~요`) 어미를 검출한다.
3. 결과를 두 갈래로 보고한다:
   - **■ 수정 권장 (본문)** — 합니다체로 고쳐야 할 본문. 본문 위반이 1건이라도 있으면 종료코드 1.
   - **□ 검토 필요 (인용)** — 따옴표/블록쿼트 안. 크루·코치 실제 발화 인용이면 그대로 둔다.

## 위반 처리

- **본문 위반:** 의미·정보·링크·숫자는 그대로 두고 **어미만** 합니다체로 고친다. (예: `정리한다`→`정리합니다`, `구조다`→`구조입니다`, `된다`→`됩니다`)
- **의도된 예외**(도구 질문 템플릿, 인용 발화)는 `{/* tone-lint:ignore-start */}` ~ `{/* tone-lint:ignore-end */}` 로 감싸 검사에서 제외한다.

## 인자

- (없음) — 전체 범위 점검 후 리포트 출력.

## 참고
