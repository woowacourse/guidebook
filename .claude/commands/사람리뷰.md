# /사람리뷰

`content/` 페이지 하나를 받아 문장 단위로 AI 냄새를 판정하고, before/after를 제시한 뒤 **사람이 고른 것만** 반영한다. 기준은 `.claude/skills/사람냄새/` (판정 데이터: `references/calibration-pairs.md`).

## 사용법

```
/사람리뷰 <content/ 경로 또는 슬러그>          # 대화형 (기본)
/사람리뷰 <경로> 자동                          # 확신 높은 '냄새남'만 반영, 나머지는 표로 보고
```

## 절차

1. **사람냄새 스킬을 로드한다.** (규칙을 기억으로 재현하지 말 것 — 판정 데이터가 갱신됐을 수 있다)
2. 대상 파일을 읽고 본문을 문장 단위로 분해한다. 코드블록·JSX 컴포넌트·frontmatter·링크·앵커용 헤딩은 제외.
3. 문장마다 판정한다: **통과 / 경계선 / 냄새남** (+근거 규칙 번호). 판정 표를 먼저 보여준다.
4. 냄새남 문장만 다듬은 버전을 제안한다 (스킬 출력 형식).
5. 사용자가 거른다: 전부 반영 / 번호 선택 / 직접 수정. **직접 수정한 문장은 calibration-pairs.md에 쌍으로 추가한다** (스킬이 자라는 경로).
6. 반영 후 `npm run lint:tone` 통과 확인, 대상 파일만 커밋.

## 경계

- 쓰는 곳: 대상 `content/` 파일, `.claude/skills/사람냄새/references/calibration-pairs.md`(5단계에서만)
- 절대 손대지 않는 곳: 숫자·고유명사·링크·컴포넌트, `.claude/skills/사람냄새/SKILL.md`의 규칙(사람만 수정), 다른 content 파일
