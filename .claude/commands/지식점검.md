# 지식 점검 (lint)

> `knowledge/` 위키의 정합성을 4종 lint + 정합성 검사로 점검. 읽기 전용 — 파일 수정 안 함. 결과를 `log.md` 에 기록하고 사용자에게 다음 액션 제안. 카파시 정통의 "weekly health check" 단계.

> **반드시 `knowledge-wiki` 스킬을 먼저 로드한다.** 모든 규약·금지 사항은 거기 있다.

## 인자

| 인자 | 동작 |
|---|---|
| (없음) | 전체 위키 lint |
| `--요약` | 발견 개수만 표시 (전체 검사 후 짧은 요약) |
| `--차원 <name>` | 특정 차원만 (`모순` \| `고아` \| `미생성` \| `낡음` \| `정합성`) |

## 진입 시 첫 출력 (체크리스트)

```
지식 점검은 4종 lint + 정합성 검사로 진행합니다.

[ ] 1. 위키 상태 스냅샷 (wiki 개수·index 라인·log 마지막 이벤트)    ← 진행 중
[ ] 2. wiki-linter 에이전트에 위임 (4 차원 + 정합성)
[ ] 3. 발견 사항 분류·우선순위 부여
[ ] 4. log.md 에 lint 이벤트 기록 + 사용자에게 다음 액션 제안
```

## Step 1: 위키 상태 스냅샷

메인이 빠르게 측정 (에이전트 호출 전):

- `knowledge/wiki/*.md` 개수
- `knowledge/index.md` 라인 수와 last_updated
- `knowledge/log.md` 마지막 5개 이벤트
- `knowledge/raw/` 전체 파일 수

상태가 비어 있으면("위키 노트 0개"), `/지식정제` 부터 실행하라고 안내하고 종료.

## Step 2: wiki-linter 에이전트에 위임

`Agent` 도구로 `wiki-linter` 에이전트 호출. 입력:

- `knowledge/AGENTS.md` 의 wiki 규약 (frontmatter 필수 필드·금지 사항)
- 검사 대상 wiki 노트 목록
- `knowledge/index.md` 전체
- `knowledge/raw/` 파일 목록
- `knowledge/log.md` 최근 항목

에이전트는 4종 lint + 정합성을 차원별로 수행해 정해진 출력 프로토콜로 발견 사항을 반환한다. **에이전트는 파일을 수정하지 않는다** — 보고만.

## Step 3: 발견 사항 분류

에이전트 결과를 메인이 받아 사용자에게 보여줄 형식으로 정리:

```
## 지식 점검 결과 (YYYY-MM-DD)

위키 상태: wiki N개 · index N라인 · raw N개

### 🔴 즉시 수정 (정합성 깨짐)
- ...

### 🟡 검토 필요 (모순·고아)
- ...

### 🟢 관찰 (낡음·stub 누적)
- ...

### 발견 없음
- (해당 차원에 이슈 0개일 때 명시)
```

각 발견에 다음 메타 부여:
- **차원** (`모순`/`고아`/`미생성`/`낡음`/`정합성`)
- **우선순위** (🔴 즉시 / 🟡 검토 / 🟢 관찰)
- **권장 액션** (한 줄)

## Step 4: log.md 기록 + 다음 액션 제안

`knowledge/log.md` 맨 위에 한 줄 추가:

```markdown
## [YYYY-MM-DD] lint
위키 N개 검사 — 🔴N개 / 🟡N개 / 🟢N개. (가장 큰 발견 한 줄 요약)
```

사용자에게:

- 🔴 발견이 있으면: "수정할까요? (특정 액션 또는 별도 PR 권장)"
- 🟡 만 있으면: "검토 후 결정"
- 🟢 만 또는 0개: "위키 건강"

## 절대 금지

- ❌ wiki / raw / index.md 어떤 파일도 수정 (읽기 전용 lint)
- ❌ "발견은 있는데 어쩌고…" 같은 모호한 결론 — 발견은 0개면 0개, 있으면 명시.
- ❌ 같은 차원에서 동일 항목 중복 보고
- ❌ 에이전트 결과를 통째 출력 — 메인이 분류·우선순위 부여 후 사용자에게 정돈된 포맷으로

## 빈도 권장

- 사용자 호출 주기: 주 1회, 또는 `/지식정제` 직후
- `/지식정제` 직후 호출이 가장 가치 — 새 노트의 정합성을 즉시 검증

## 예시

```
사용자: /지식점검

LLM:    [Step 1] 위키 상태:
        - wiki 10개 · index 10라인 · raw 5개
        - log 마지막: 2026-06-09 compile

        [Step 2] wiki-linter 호출 중...

[에이전트 작업 후]

LLM:    [Step 3 결과]

        ## 지식 점검 결과 (2026-06-09)

        ### 🟡 검토 필요 (2건)
        - [낡음] wiki/measurable-learning-goal — updated 30일 경과 (사실은 아님, 예시).
        - [고아] wiki/agent-debate-curriculum-design — 들어오는 링크 0건. teach-by-silence 와 양방향 가능.

        ### 🟢 관찰 (1건)
        - [stub 누적] 보류 6개(stone-and-heen 등)가 log에 남아있음. 다음 raw 흡수 시 검토.

        ### 발견 없음
        - 모순: 0건
        - 미생성: 0건
        - 정합성: 0건 (sources·links 모두 실재)

        [Step 4] log.md 갱신: lint 한 줄 기록
        다음: 🟡 2건 검토 후 별도 PR 또는 다음 정제 시 함께 처리?

사용자: ...
```
