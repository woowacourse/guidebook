# 지식 흡수 (ingest)

> 새 1차 자료를 `llm-wiki/raw/` 에 빠르게 dump. 이 커맨드는 **컴파일하지 않는다** — wiki/ 갱신은 별도 `/지식정제`. 카파시 정통의 ingest/compile 분리 원칙을 따른다.

> **반드시 `llm-wiki` 스킬을 먼저 로드한다.** 모든 규약·금지 사항은 거기 있다.

## 진입 시 첫 출력 (체크리스트)

```
지식 흡수는 4단계로 진행합니다.

[ ] 1. 원본 자료 받기 (경로 또는 인라인 텍스트)        ← 진행 중
[ ] 2. 분류 결정 (raw 루트 / conversations / external / assets)
[ ] 3. 파일명·frontmatter 규격화
[ ] 4. raw/ 에 기록 + log.md 에 한 줄
```

단계가 바뀔 때마다 다시 출력 (상태 마커: `[ ]` `[ ] ← 진행 중` `[x]`).

## Step 1: 원본 받기

사용자가 다음 중 하나를 넘긴다:
- 파일 경로 (예: `.inbox/notes.md`, 임의의 마크다운/텍스트 파일)
- 인라인 텍스트 (대화 사본·관찰 노트 등을 직접 붙여넣음)
- URL (외부 자료) — 이 경우 사용자에게 본문을 마크다운으로 가져오는 방법을 한 번 확인 (`firecrawl-scrape` 등)

여러 개를 한 번에 받는 것 OK. 각각 Step 2~4 반복.

## Step 2: 분류 결정 (4지선다)

| 분류 | 위치 | 트리거 |
|---|---|---|
| **실험 로그·회고·관찰** | `llm-wiki/raw/` 루트에 flat | 코치가 실험 후 작성한 거친 메모, 회고록, 자기 관찰 |
| **대화 사본** | `llm-wiki/raw/conversations/` | 코치-크루, 크루-크루 대화 발췌. 익명화 필요 시 본문에 명시 |
| **외부 자료** | `llm-wiki/raw/external/` | 책·논문·아티클·강연 발췌. 반드시 출처 표기 |
| **이미지·스크린샷** | `llm-wiki/raw/assets/` | 텍스트로 안 읽는 시각 자료 |

애매하면 사용자에게 묻는다. 새 폴더는 절대 만들지 않는다 (스킬 절대 규칙).

## Step 3: 파일명·frontmatter 규격화

**파일명**: `YYYY-MM-DD-슬러그.md` (kebab-case 한국어 OK).
- 날짜는 자료가 *발생한 날*. 모르면 오늘 날짜.
- 슬러그는 의미 식별자. 너무 길면 자른다.

**frontmatter** 보강 (사용자 메타데이터를 받아 자동 채움):
```yaml
---
source_type: log | retrospective | conversation | external | observation
author: 작성자 (모르면 생략)
captured: YYYY-MM-DD
---

(원본 본문 그대로)
```

원본을 임의 정리하지 말 것. **raw는 불변** — 들어온 모양 그대로 보존.

## Step 4: 기록 + 로그

1. 파일을 결정된 경로에 `Write` 로 저장.
2. `llm-wiki/log.md` 맨 위에 한 줄 추가:
   ```markdown
   ## [YYYY-MM-DD] ingest | raw/<경로>
   N개 흡수. (출처·작성자 메타 짧게)
   ```
3. 사용자에게 결과 보고:
   - 어디에 저장됐는지 (전체 경로)
   - 누적된 raw 개수 (대략)
   - 다음 권장: "정제하려면 `/지식정제` 실행"

## 컴파일 트리거하지 않기

이 커맨드는 wiki/ 를 건드리지 않는다. index.md 도 갱신하지 않는다. **순수히 raw 적재만**.

이유: 사람의 캡처 속도와 LLM의 정제 속도를 분리. 캡처는 항상 0초로 끝나야 사고 흐름이 안 막힘.

## 절대 금지

- ❌ raw 기존 파일 수정 (덮어쓰기, 오타 정정 포함)
- ❌ 새 하위 폴더 생성 (위 3개 외)
- ❌ wiki/ 또는 index.md 갱신
- ❌ 본문 임의 편집·요약·정리

## 예시

```
사용자: /지식흡수
        오늘 페어 코칭 세션에서 크루가 "리뷰가 무서워서 PR을 안 올리게 된다" 고 말함.
        이건 심리적 안전감 약함의 신호 같다.

LLM:    [Step 1 완료, Step 2 진입]
        이건 코치 관찰이라 raw/ 루트가 적절합니다.
        파일명 후보: 2026-06-09-pair-coach-pr-fear.md
        괜찮나요?

사용자: 좋아

LLM:    [Step 3 → Step 4]
        ✓ llm-wiki/raw/2026-06-09-pair-coach-pr-fear.md 생성
        ✓ llm-wiki/log.md 에 ingest 1줄 추가
        누적 raw: 1개 (luxuriously, 위키가 막 시작됨)
        다음: 더 흡수하거나, /지식정제 로 wiki 합성
```
