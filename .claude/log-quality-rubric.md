# 실험 로그 품질 루브릭

> 이 파일은 autoresearch의 `prepare.py`에 해당한다.
> **절대 수정하지 않는다.** 평가 기준이 바뀌면 모든 이전 점수와 비교가 불가능해진다.
> 루브릭을 개선하고 싶으면 사람이 직접 이 파일을 수정한다.

## 평가 차원 (5개, 각 1~5점, 총점 25점)

### D1. 구조 완성도 (Structure)

실험 로그가 필수 섹션을 갖추고 있는가?

| 점수 | 기준 |
|------|------|
| 5 | Callout(대상/맥락/핵심질문) + 배경 + 설계 + 결과 + 교훈 + 다음실험제안 — 모두 실질적 내용 |
| 4 | 모든 섹션 존재하나 1개 섹션이 얇음 (1~2문장) |
| 3 | 1개 섹션 누락 또는 2개 이상 섹션이 얇음 |
| 2 | 2개 이상 섹션 누락 |
| 1 | 배경+설계만 있고 결과/교훈 없음 (미완성) |

### D2. 구체성 (Specificity)

추상적 서술 대신 구체적 사례, 데이터, 인용이 있는가?

| 점수 | 기준 |
|------|------|
| 5 | 수치 데이터 + 크루 반응 인용/사례 + 구체적 타임라인이 모두 포함 |
| 4 | 위 3가지 중 2가지 포함 |
| 3 | 위 3가지 중 1가지 포함 |
| 2 | 모두 추상적이나 예시가 간헐적으로 등장 |
| 1 | 전체가 추상적 서술 ("좋았다", "효과적이었다" 수준) |

### D3. 전이 가능성 (Transferability)

다른 코치가 이 로그만 읽고 동일한 활동을 설계할 수 있는가?

| 점수 | 기준 |
|------|------|
| 5 | 운영 구조, 타임라인, 요구사항, 템플릿/자료 링크가 모두 있어 그대로 복제 가능 |
| 4 | 대부분 복제 가능하나 암묵적 전제 1~2개가 설명 없음 |
| 3 | 큰 흐름은 따라갈 수 있으나 세부 운영 방법은 추측 필요 |
| 2 | 아이디어 수준의 영감은 얻으나 실행 방법은 별도 설계 필요 |
| 1 | 활동 결과만 있고 어떻게 했는지 알 수 없음 |

### D4. 교훈의 양면성 (Balanced Lessons)

성공과 실패를 균형있게 다루고, 교훈이 다음 행동으로 연결되는가?

| 점수 | 기준 |
|------|------|
| 5 | 잘된 것 + 개선점이 균형 있고, 각각 구체적 근거 + 다음 실험 제안이 행동 가능 |
| 4 | 양면 모두 있으나 한쪽이 상대적으로 얇음 |
| 3 | 한쪽만 구체적이고 다른 쪽은 형식적 |
| 2 | 성공만 서술하거나 실패만 서술 |
| 1 | 교훈 섹션 자체가 없거나 "업데이트 예정" |

### D5. 원본 자료 연결 (Source Linkage)

디스커션, 슬라이드, 스프레드시트 등 원본 자료가 연결되어 있는가?

| 점수 | 기준 |
|------|------|
| 5 | 활동에 사용된 주요 자료(디스커션, 슬라이드, 템플릿) + 크루 결과물 링크 |
| 4 | 주요 자료 링크는 있으나 크루 결과물 링크 누락 |
| 3 | 원본 디스커션/슬라이드 중 일부만 링크 |
| 2 | 참조만 있고 클릭 가능한 링크 없음 |
| 1 | 원본 자료 언급 자체가 없음 |

## 총점 해석

| 범위 | 등급 | 의미 |
|------|------|------|
| 21~25 | A | 다른 코치가 그대로 재현 가능한 완성 로그 |
| 16~20 | B | 핵심은 전달되나 1~2개 차원 보강 필요 |
| 11~15 | C | 아이디어는 좋으나 실행 세부사항 부족 |
| 6~10 | D | 초안 수준, 대폭 보강 필요 |
| 5 | F | 골격만 존재 |
