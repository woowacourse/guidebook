# 로그 품질 평가 및 개선

## 시작 전 필수

`.claude/log-quality-rubric.md`를 읽는다. 5개 차원(D1~D5)과 점수 기준이 여기에 있다.

## 로그 파일 경로 찾기

1. `content/logs.ts`에서 slug 확인
2. 파일 경로: `content/education/logs/{slug}.mdx` 또는 하위 디렉토리 탐색

## 평가 절차

1. MDX 파일을 읽는다
2. 5개 차원(D1~D5)으로 각각 1~5점 평가
3. 총점으로 등급 결정:
   - A: 21~25점
   - B: 16~20점
   - C: 11~15점
   - D: 6~10점
   - F: 1~5점

## 개선 절차

B등급(16점) 미만 로그에 대해:
1. 가장 낮은 차원을 찾는다
2. 해당 차원만 타겟으로 MDX를 수정한다
3. 수정 후 재평가한다
4. 점수가 올랐으면 다음 낮은 차원으로 이동
5. B등급 달성 또는 5회 도달 시 종료

## 수정 제약

- 마커 섹션(`<!-- AUTO:START -->` ~ `<!-- AUTO:END -->`) 안에서만 수정 가능
- 수치·인용을 지어내지 않는다
- 로그의 사실 관계를 변경하지 않는다 (어투·구조·상세화만 허용)
- 루브릭 파일(`.claude/log-quality-rubric.md`)은 절대 수정하지 않는다

## 출력 형식

```
## 품질 평가: {로그 제목}

| 차원 | 점수 | 근거 (루브릭 기준 인용) |
|------|------|----------------------|
| D1. ... | ?/5 | ... |
| D2. ... | ?/5 | ... |
| D3. ... | ?/5 | ... |
| D4. ... | ?/5 | ... |
| D5. ... | ?/5 | ... |
| **총점** | **?/25** | **{등급}** |

### 개선 계획 (B등급 미만인 경우)
- 우선 개선 차원: {차원명} ({점수}/5)
- 개선 방향: {구체적 방향 1~2문장}
```
