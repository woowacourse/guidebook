# 문장 다듬기 (sentence-polish)

`content/` 본문 문장에서 **AI가 쓴 티는 걷어내고, 사람이 쓴 느낌과 원작자의 목소리는 드러나게** 다듬는다.
목표는 "더 매끄럽게"가 아니라 **"화자를 되살리되 원문의 결은 그대로"** 다.

## 이 스킬이 아닌 것 (완전 독립)

- **humanizer 아님** — 메이커준 개인 톤으로 *수렴*시키지 않는다. register는 원문 저자를 따른다.
- **말투점검 아님** — 합니다체 통일 검사가 아니다. 문체(종결어미) 교정은 하지 않는다.
- **내용 교정 아님** — 개념·난이도·사실·숫자를 바꾸지 않는다(아래 게이트·플래그 참조).

## 핵심 원칙 (왜 이렇게 다듬는가)

1. **목소리의 신호 = 화자의 존재.** 능동으로 말하는가, 독자를 의식하는가, 바람·판단을 직접 내놓는가. **단어의 생생함·구체성은 목소리의 증거가 아니다.**
2. **비유 ≠ 목소리.** 생생한 비유("증발합니다")는 오히려 연출 티일 수 있다. 다듬기로 비유를 *더하지 않는다.*
3. **register(절제↔생생)는 원문을 따른다.** 절제된 문장을 펀치로 올리지 않고, 생생한 문장을 깎지 않는다.
4. **과감하되, 사람이 최종 판단.** 공격적으로 고치되 항상 before/after를 보여주고 사람이 거른다.

## 다듬는 순서

### A0 — do-no-harm 게이트 (가장 먼저)
문장을 고치기 전에 묻는다: **"이미 화자가 살아있는가?"**
- 살아있으면 → **고치지 말고 "이미 살아있음 — 손댈 AI 티 없음"으로 통과**시킨다. 과감함은 *AI 티가 있을 때만* 발동한다.
- 죽어있으면(화자 지운 수동태·추상 명사화 등) → A1~A4로 다듬는다.

### A. AI 티 제거 (화자 되살리기)
- **A1.** 행위자 지운 수동태 → 자동사/능동. *단,* 명시 화자("우리가 봤더니") 주입은 **문서 종류별** — 분석 문서(insights)는 비인칭 유지, 화자조 문서(philosophy 논쟁조·index 바람조)는 화자 살림.
- **A2.** 개념을 흐리는 비유적 framing 단어 → 평이한 단어("리듬"→"구조"). 과잉 비유·펀치 의심.
- **A3.** 군더더기·의미 없는 헤지 정리("4개 이상의 로그에서"→"로그 4개에서").
- **A4.** 추상 명사화·병렬구조 과잉 풀기.

### B. 목소리 보존 (넘지 말 것)
- **B1.** register는 원문 따름.
- **B2.** 화자의 태도·수사적 move(독자 의식, 바람·판단 표명) 보존·강화.
- **B3.** 저자 고유 어휘 보존 — framing 단어가 개념을 흐릴 때만 평이화를 *제안*(강제 아님).
- **B4.** 내용 난이도·개념은 안 바꾼다. 어려운 표현은 *플래그만* 한다(저자 몫).

## 출력 형식 (항상)

```
원문   : <그대로>
다듬음 : <결과>   (또는 "이미 살아있음 — 변경 없음")
바꾼 것: <move 한 줄 요약>
⚠️ 확인: <숫자·고유명사·주장을 건드렸으면 그 지점>   (없으면 생략)
```

조용한 바꿔치기 금지. 사실 검증은 사람 몫이되, **건드린 위치는 스킬이 ⚠️로 가리킨다.**

## 예시

### 예시 1 — AI-flat 문장 (다듬음)
```
원문   : 4개 이상의 로그에서 … "제약 → 해제 → 통합" 리듬이 독립적으로 발견되었습니다.
다듬음 : 서로 다른 레벨의 로그 4개에서 "제약 → 해제 → 통합" 구조가 반복적으로 드러났습니다.
바꾼 것: 수동태 해제(발견되었습니다→드러났습니다), 비유 단어 평이화(리듬→구조), 군더더기 정리. 분석 문서라 화자는 안 넣음.
⚠️ 확인: "독립적으로→반복적으로"는 뜻이 미묘하게 약해짐 — 일반화 근거를 유지할지 확인.
```

### 예시 2 — 이미 살아있는 문장 (A0 게이트 통과)
```
원문   : 그렇다고 이 말이 멋있어서 내건 구호는 아닙니다. … 원칙은 거기서 귀납해 뒤따라 정리했습니다.
다듬음 : 이미 살아있음 — 변경 없음. (독자 의심을 받아치는 화자 move + 능동. AI 티 없음.)
```

### ✗ 하면 안 되는 것 — over-reach
```
✗ 이는 듣기 좋은 구호가 아니라, 매주 축적된 실험 로그에서 귀납적으로 정리한 원칙입니다.
```
→ "과감하게"를 *이미 살아있는* 문장에 적용하면 화자가 다시 증발해 AI-flat으로 회귀한다. A0 게이트가 이걸 막는다.
