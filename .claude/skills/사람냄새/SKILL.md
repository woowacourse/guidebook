# 사람냄새

`content/` 본문에서 **AI가 쓴 냄새를 걷어내고 사람이 손으로 쓴 문장으로 되돌린다.**

## 핵심 전제 — 기준의 출처

'사람 냄새'의 정의는 이 문서가 아니라 **메이커준의 판정 데이터**([references/calibration-pairs.md](references/calibration-pairs.md))에 있다. 아래 규칙은 그 판정에서 역산한 것이다. 따라서:

- **에이전트는 규칙을 스스로 추가·수정하지 않는다.** 새 규칙은 새 판정 쌍(사람이 직접 고친 before/after)에서만 나온다. (루브릭 수정 원칙과 동일)
- 규칙과 판정 데이터가 충돌하면 **판정 데이터가 이긴다.**
- 에이전트의 다듬은 버전도 결국 AI가 쓴 것이다. 제안까지가 에이전트 몫, 최종 판단은 사람 몫.

## 검출 규칙 (v1 — 2026-07-03 캘리브레이션)

1. **완결 선언 → 시도 서술.** "~로 남겼습니다/정리했습니다" 같은 단호한 완료·성취 서술을 "~하려고 했습니다"로. 사람은 자기 일을 성취가 아니라 시도로 말한다.
2. **사물 의인화 제거.** 기록이 "가리키고", 문장이 "말하고", 질문이 "밀어 주는" 구조 금지. 발견·행위의 주체는 사람. ("기록이 가리킨 것" → "기록들에서 발견한")
3. **연출된 강조 해체.** 부사쌍("가장 또렷하게, 그리고 되풀이해서"), 관용구 재치·짧은 펀치 문장("따로 놀지 않습니다"), 대구법. **짧고 멋진 문장 자체가 AI 냄새다.** 평이한 설명문이 낫다.
4. **판단의 소유 표시.** "중요하다고 생각하는"처럼 판단 주체를 드러낸다. 데이터가 스스로 말하는 척 금지.
5. **실무 문서투 허용.** "아래와 같습니다", 아라비아 숫자("3가지"), 복수 "들"(교육들·시도들). 세련미를 깎는 표현이 오히려 사람 냄새다.
6. **거창한 어휘보다 작업 어휘.** "원칙"(grand) 대신 "패턴"·"방향성"(팀이 실제로 쓰는 말).
7. **제조된 정밀함 금지.** 실제와 다를 수 있는 빈도·리듬 연출("매주") 제거.
8. **잠정성은 그 자리에.** "바뀔 수 있습니다"를 Callout·각주로 미루지 않고 주장 바로 뒤에 쓴다.
9. **양보 부정 선호.** 범주 부정 "X가 아닙니다"보다 "X는 아닙니다".
10. **(규칙 아님, 신호만)** 사람 손은 정서법을 흘린다(여러번·개선되서). 흉내 내지 않는다 — 발행 시 맞춤법은 지키되, 교정을 핑계로 문장을 다시 '우아하게' 만들지 않는다.

## 다른 스킬과의 관계

- **sentence-polish 대체.** 그 스킬의 A0 게이트는 수사적 펀치·의인화를 "살아있는 화자"로 보호했지만, 캘리브레이션 결과 메이커준의 코는 정확히 그것들을 AI 냄새로 판정했다. 규칙 2·3이 A0보다 우선한다.
- **humanizer 아님** — 전역 개인 톤 스킬과 독립. 다만 금지어(리듬·여정·em-dash 부연)는 규칙 3·7과 상호 보강.
- **말투점검 아님** — 종결어미(합니다체)는 건드리지 않는다. 반영 후 `npm run lint:tone`으로 확인만.

## 절차

1. 대상 본문을 문장 단위로 분해한다 (코드블록·JSX 컴포넌트·frontmatter·링크 제외).
2. 문장마다 판정한다: **통과 / 경계선 / 냄새남** (+근거 규칙 번호).
3. 냄새남 문장만 다듬은 버전을 제안한다. 경계선은 플래그만.
4. 사람이 제안을 거르거나 직접 고친다. **직접 고친 버전은 반드시 calibration-pairs.md에 쌍으로 추가한다** — 이것이 스킬이 자라는 유일한 경로다.

## 출력 형식

```
원문   : <그대로>
판정   : 냄새남 (규칙 2·3) | 경계선 (규칙 6) | 통과
다듬음 : <제안>   (통과면 생략)
⚠️ 확인: <숫자·고유명사·주장을 건드렸으면 그 지점>
```

## 불변 조건

- 숫자·고유명사·링크·JSX 컴포넌트·frontmatter·앵커용 헤딩은 바꾸지 않는다.
- 합니다체 유지. 반영 후 `npm run lint:tone` 통과 확인.
- MDX 볼드는 한글 글자에서 닫는다 (`**…장**입니다` OK, `**…"**조사` 깨짐).
