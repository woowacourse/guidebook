# 도구 승격 루브릭

> 이 파일은 autoresearch의 `prepare.py`에 해당한다.
> **절대 수정하지 않는다.** 평가 기준이 바뀌면 모든 이전 판정과 비교가 불가능해진다.
> 루브릭을 개선하고 싶으면 사람이 직접 이 파일을 수정한다.

## 목적

실험 로그 안에 **다른 코치가 복사해서 바로 사용할 수 있는 도구**(프롬프트, 워크플로우, 템플릿, 체크리스트)가
포함되어 있는지 판정한다. 승격 대상이 있으면 `content/education-experiment/tools/`로 분리한다.

## 승격 기준 (4개 차원, 각 Yes/No, 3개 이상 Yes면 승격)

### T1. 재사용 가능한 산출물 존재

로그 안에 프롬프트 전문, 워크플로우 단계, 템플릿, 체크리스트 등
**복사-붙여넣기로 즉시 사용 가능한 산출물**이 있는가?

| 판정 | 기준 |
|------|------|
| Yes | 프롬프트 전문, 단계별 워크플로우, 템플릿, 체크리스트 중 1개 이상이 본문에 있음 |
| No | 아이디어나 원칙만 있고, 바로 사용 가능한 산출물 없음 |

### T2. 맥락 독립성

산출물이 해당 실험의 특정 맥락(특정 기수, 특정 크루)에 종속되지 않고,
다른 상황에서도 사용 가능한가?

| 판정 | 기준 |
|------|------|
| Yes | 대상/시기를 바꿔도 그대로 사용 가능하거나, 최소한의 변수 치환으로 사용 가능 |
| No | 특정 기수/크루/상황에 깊이 종속되어 범용 사용 불가 |

### T3. 실험을 통한 검증

산출물이 실제 실험에서 사용되었고, 효과가 확인되었는가?

| 판정 | 기준 |
|------|------|
| Yes | 로그에 사용 결과(크루 반응, 정성/정량 피드백)가 기록됨 |
| No | 미사용이거나, 사용했으나 결과 기록 없음 |

### T4. 자기 완결성

산출물만으로 사용법을 이해할 수 있는가? (별도 설명 없이 사용 가능)

| 판정 | 기준 |
|------|------|
| Yes | 산출물 자체에 사용법/목적/입출력이 포함되어 있거나 자명함 |
| No | 로그 본문의 맥락 설명 없이는 사용법을 알 수 없음 |

## 판정 규칙

- **4/4 Yes** → 즉시 승격. 산출물을 `tools/`에 독립 MDX로 분리.
- **3/4 Yes** → 승격 후 보강. 산출물을 분리하되, No인 차원을 도구 페이지에서 보완.
- **2/4 이하** → 승격 보류. 로그 개선(`/improve-log`)으로 산출물 품질을 먼저 올린다.

## 승격 시 수행 작업

1. `content/education-experiment/tools/{slug}.mdx` 생성 — 산출물 + 사용법 + 출처 로그 링크
2. `content/education-experiment/tools/_meta.ts`에 항목 추가
3. `content/education-experiment/tools/index.mdx`에 링크 추가
4. `content/updates.ts` 배열 맨 위에 항목 추가 (status: 'active')
5. 원본 로그에 도구 링크 추가 (Callout으로 "이 실험에서 검증된 도구" 안내)

## 평가 출력 형식

```
## 도구 승격 평가: {로그 제목}

| 차원 | 판정 | 근거 (1문장) |
|------|------|-------------|
| T1. 재사용 산출물 | Yes/No | ... |
| T2. 맥락 독립성 | Yes/No | ... |
| T3. 실험 검증 | Yes/No | ... |
| T4. 자기 완결성 | Yes/No | ... |

**결과**: {즉시 승격 / 승격 후 보강 / 승격 보류}
**승격 대상**: {산출물 이름} (없으면 "해당 없음")
```
