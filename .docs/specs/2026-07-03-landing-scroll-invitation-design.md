# 랜딩 스크롤 유도 설계 — "완결된 선언"을 "이야기의 첫 장"으로

- 날짜: 2026-07-03
- 배경: 랜딩 첫 진입 시 아래에 콘텐츠가 더 있다는 것을 인지하기 어렵다는 피드백 (데스크톱/노트북 환경)
- 결정: 안 A(CTA 역할 전환) + 안 B(별 트레일) 결합, 공통 기반 포함

## 문제 진단 (실측 기반)

localhost:3000 헤드리스 캡처(1440×820 / 1728×950 / 390×740) 결과:

1. **구도가 완결돼 보인다** — 가운데 정렬 + 대칭 + 어두운 CTA 버튼이 시선의 종착점을 만든다. 다음 섹션 제목이 fold에 살짝 걸치지만, CTA와의 사이 ~120px 여백이 "페이지 끝" 인상을 준다.
2. **첫 화면의 행동이 서사와 어긋난다** — 랜딩 서사는 Hero(열망) → TecoWay(현장) → CrewVoiceMap(흔적) → CrewJourney(확산) → EnterDocs(닫는 초대)인데, hero CTA가 EnterDocs와 같은 목적지(/education)로 바로 보내 서사를 건너뛰게 한다.
3. **Reveal 숨김 엣지 케이스** — `components/Reveal.tsx`의 `rootMargin: '0px 0px -10% 0px'` 때문에, 로드 시점에 뷰포트 하단 10% 구간에 걸친 섹션은 `opacity: 0`으로 남는다. 특정 화면 높이에서는 fold 아래 콘텐츠가 실제로 숨겨져 순수 여백만 보인다.
4. **스크롤 단서 부재** — macOS 오버레이 스크롤바는 스크롤 전엔 안 보이고, 랜딩엔 스크롤 큐가 없다 (education/index.mdx에는 `.scroll-cue` 패턴 존재).

## 사용자 결정 사항

| 질문 | 답 |
|---|---|
| 피드백 환경 | 데스크톱/노트북 (모바일도 같은 변경 적용) |
| 첫 화면 1순위 행동 | 스크롤로 이야기 보기 — CTA는 여정의 마무리(EnterDocs)로 |
| 개입 강도 | 적극적 장치 허용 |
| 접근 | A + B 결합 |
| 주 CTA 문구 | "우테코의 10개월 먼저 보기 ↓" |

## 설계

### 성공 기준

1440×820에서 ① 점선 트레일이 fold에 잘린 채 보인다, ② 첫 화면의 주 행동이 아래로 향한다, ③ 어떤 뷰포트 높이에서도 fold 아래 콘텐츠가 투명 상태로 숨지 않는다.

### 공통 기반

- **Reveal 마운트 검사**: `components/Reveal.tsx`에서 마운트 시 `getBoundingClientRect().top < window.innerHeight`면 IntersectionObserver 없이 즉시 `shown`. 초기 상태가 `opacity: 0`이므로 이 전환이 로드 직후 한 박자 늦게 떠오르는 fade-up이 된다(안 C의 로드 안무 연장 효과가 부수적으로 포함됨).
- **여백 조정**: Hero `padding-bottom`(3rem)은 트레일이 여백을 채우므로 소폭만 조정. 실측 스크린샷으로 튜닝.

### 안 A — CTA 역할 전환

- 주 CTA: `우테코 교육 들여다보기 → /education` ⟶ **`우테코의 10개월 먼저 보기 ↓ → #teco-way` 앵커 스크롤**. 도착지 섹션 eyebrow("우테코의 10개월")를 그대로 불러 클릭 후 확인이 되게 한다.
- TecoWay 섹션에 `id="teco-way"` 부여.
- `html { scroll-behavior: smooth }` 추가 — `prefers-reduced-motion`이면 브라우저가 즉시 점프로 대체하도록 미디어 쿼리로 감싼다.
- 보조 링크: CTA 아래 작은 텍스트 링크 **"문서로 바로 가기 →"**(/education) — 직행 독자 동선 보존. Hero에 `secondaryCta` 프롭 추가(Hero는 content/index.mdx에서만 사용, 파급 없음).
- 앵커 방식이므로 Hero는 서버 컴포넌트 유지.

### 안 B — 별 트레일

- CTA·보조 링크 아래 중앙에서 시작해 TecoWay 방향으로 내려가는 **세로 점선**을 Hero 하단에 그린다.
- 스타일: TecoWay 여정선과 동일한 `2px dashed rgba(55, 53, 47, 0.25)`(다크: `rgba(255, 255, 255, 0.28)` — TecoWay.module.css 244행과 동일 값) 재사용 — 별 아래로 난 길이 10개월 여정의 점선으로 이어진다는 모티프 연결.
- 길이: 노트북 fold(≈820px 뷰포트)에서 반드시 잘리도록. 잘림 자체가 "길이 계속된다"는 신호.
- 모션: 로드 안무 마지막 박자에 위→아래로 그려지는 등장 1회만. 상시 반복 애니메이션은 '조용한 선언' 톤을 해치므로 금지. `prefers-reduced-motion` 시 정적 표시.
- Hero는 `overflow-x: clip`이므로 세로선인 한 가로 오버플로우 위험 없음.

### 검증

- 헤드리스 스크린샷 3종(1440×820 / 1728×950 / 390×740) 재캡처 — 트레일 fold 걸침, 다음 섹션 제목 노출 확인.
- 모바일 가로 오버플로우 점검 (모바일점검 스킬 기준).
- `prefers-reduced-motion` 동작 확인 (트레일 정적, 스크롤 즉시 점프, Reveal 즉시 표시).

## 구현 후 조정 (2026-07-03)

실제 화면 검토 후 사용자 판단으로 **안 B(별 트레일)와 보조 링크('문서로 바로 가기 →')를 제거**했다 — 섹션을 잇는 선이 의미 없이 길고 불필요해 보인다는 피드백. 유지된 것: 주 CTA의 스크롤 초대 전환("우테코의 10개월 먼저 보기 ↓" → #teco-way), Reveal fold 숨김 수정, smooth scroll, scroll-margin. Hero 하단 패딩은 3rem → 2rem으로 소폭 줄여 TecoWay 제목이 fold 위로 걸치게 했다(fold가 여백이 아니라 콘텐츠를 가로지르도록). 트레일 구현은 커밋 09a78dd에 보존되어 있어 필요 시 복원 가능하다.

## 범위 밖

- education/index.mdx의 기존 `.scroll-cue`는 손대지 않는다.
- TecoWay 이하 섹션의 내용·레이아웃 변경 없음 (id 부여 제외).
- 모바일 전용 최적화는 이번 범위 아님 (같은 변경이 모바일에도 적용되는 수준까지만).
