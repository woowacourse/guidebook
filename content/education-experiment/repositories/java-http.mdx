# 자바 HTTP 미션 (톰캣 직접 구현, Java)

> [GitHub: woowacourse/java-http](https://github.com/woowacourse/java-http)
>
> 분석 티어: T2 · 점수: 22/25 · 마지막 스캔: 2026-07-03

## 개요

자바로 HTTP 서버(톰캣)를 직접 구현하는 미션으로, 385회 포크와 1,104개 PR이 누적된 대규모 활성 레포지토리입니다. 학습 목표는 웹 서버의 작동 원리(HTTP 파싱, 스레드풀, 서블릿 생명주기)를 직접 구현하며 체득하는 것입니다. 2024년부터 AI 코드 리뷰 봇이 도입되면서 사양·보안·테스트 관점의 자동 리뷰 밀도도 함께 높아졌습니다.

## 주요 발견

- **HTTP 파싱 정확성**: 쿠키 헤더 파싱 시 공백 미제거로 키 미스매치가 반복 발생. `Cookie: a=1; b=2` 형식에서 `b` 앞 공백이 `get("b")` 실패를 유발하며 JSESSIONID 인식 오류로 이어짐
- **세션 보안 3종**: 쿠키에 `Path`, `HttpOnly`, `Secure`, `SameSite` 속성 누락; 로그인 성공 시 Session Fixation 방지를 위한 세션 ID 재발급 미적용; `null` JSESSIONID로 세션 생성 및 공유 위험
- **에러 핸들링 일관성**: 미지원 메서드·미등록 경로에서 405·404 응답 대신 침묵(무응답); `IllegalArgumentException` 미처리로 클라이언트 타임아웃 유발
- **동시성 설계**: `synchronized` 사용 이유 미설명, 스레드풀 적용 후 공유 상태 가시성 문제
- **입력 검증 및 정보 보호**: 회원가입 중복 계정 덮어쓰기, 비밀번호 평문 저장, `User.toString()` 로그 출력 시 PII 노출
