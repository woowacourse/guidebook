# 자바 @MVC 미션

> [GitHub: woowacourse/java-mvc](https://github.com/woowacourse/java-mvc)
>
> 분석 티어: T2 · 점수: 21/25 · 마지막 스캔: 2026-04-07

## 개요

스프링 `@MVC` 프레임워크를 직접 구현하며 MVC 구조와 각 역할을 이해하는 심화 백엔드 미션이다.
379회 포크·400+ PR이 누적된 핵심 Spring 연계 미션으로, Reflection API를 활용한 어노테이션 기반 컨트롤러 등록 과정을 탐구한다.
리뷰는 Controller 반환 타입·Handler 추상화 수준·JsonView 응답 일관성·점진적 리팩토링 전략에 집중된다.

## 주요 발견

- Controller 반환 타입 일관성: `String` 뷰명 반환 vs `ModelAndView` 객체 반환 두 경우 모두 처리 가능한 설계가 반복 리뷰 주제
- Handler 추상화 수준: `HandlerAdapter` 패턴 vs `Controller`와 `HandlerExecution`을 `Handler`로 통합 추상화하는 방법 논의
- 상수 관리 구조: 자주 쓰는 뷰 경로 상수를 컨트롤러마다 중복 정의하지 않고 단일 상수 클래스로 모으는 설계 제안 다수 등장
- `getHandler` 메서드명-반환 타입 일관성: 핸들러를 반환해야 하는 메서드가 `HandlerMapping`을 반환하는 불일치가 혼란 유발
- `JsonView` 응답 형식: `writeValueAsString` vs `writeValue` 메모리 효율 차이 및 Content-Type 누락 리뷰
- 점진적 리팩토링 전략: 기존 레거시 코드를 유지하면서 신기술을 단계적으로 적용하는 방법이 핵심 학습 목표로 반복 등장
- 로그인/로그아웃 컨트롤러 책임 분리: 단일 컨트롤러에 묶는 방식 vs 분리하는 방식에 대한 설계 토론이 다수 PR에 걸쳐 나타남
