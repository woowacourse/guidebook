### Phase 1: 전체 측정

모든 실험 로그를 두 가지 기준으로 동시 평가합니다.

| 평가 | 기준 | 만점 | 목적 |
|------|------|------|------|
| **품질 점수** | D1~D5 (구조, 구체성, 전이, 교훈, 원본) | 25점 | 로그 자체의 서술 품질 |
| **승격 점수** | P1~P4 (반복, 추출, 교차, 영향력) | 20점 | 상위 레이어 승격 적격성 |

### Phase 2: 품질 개선

B등급(16점) 미만인 로그를 점수 오름차순으로 개선합니다.

### Phase 4~6: 승격 → 동기화 → 기록

| Phase | 행동 | 산출물 |
|-------|------|--------|
| **4. 승격 실행** | 도구/인사이트/교육모델에 콘텐츠 추가 | MDX 파일, `_meta.ts` 업데이트 |
| **5. 모델 동기화** | 교육 모델에 실험 근거 반영 | 교육 모델 문서 보강 |
| **6. 사이클 기록** | TSV에 결과 기록, 다음 사이클 제안 | `research-cycle-log.tsv` |

## 커맨드 체계

전체 워크플로우를 슬래시 커맨드로 실행할 수 있습니다.

| 커맨드 | 역할 | 실행 범위 |
|--------|------|-----------|
| `/review-log` | 개별 로그 품질 평가 | 단일 로그 or 전체 |
| `/improve-log` | 개별 로그 반복 개선 | 단일 로그 (최대 5회) |
| `/improve-all` | 전체 로그 순회 개선 | B등급 미만 전체 |
| `/extract-insights` | 교차 패턴 탐지 | 카테고리 or 전체 |
| `/sync-model` | 교육 모델 동기화 | 미반영 인사이트 |
| `/research-cycle` | **마스터 루프** (위 전체 포함) | 6단계 전체 사이클 |

## autoresearch 원칙과의 대응

| Karpathy autoresearch | 실험 로그 연구 사이클 | 비고 |
|---|---|---|
| `prepare.py` (불변 평가 인프라) | 품질 루브릭 + 승격 루브릭 | 사람만 수정 가능 |
| `val_bpb` (메트릭 측정) | `/review-log` (품질) + 승격 평가 (P1~P4) | 이중 평가 체계 |
| train → measure → commit/reset | `/improve-log` 루프 | 한 차원씩, 커밋/리버트 |
| 밤새 실험 순회 | `/research-cycle` 마스터 루프 | 6단계 전체 파이프라인 |
| 모델 개선 → 배포 | 승격 → 교육 모델 동기화 | **기존에 없던 단계** |
| `results.tsv` | `research-cycle-log.tsv` | 사이클 단위 기록 |
