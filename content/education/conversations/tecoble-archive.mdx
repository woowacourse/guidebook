## 테코블은 어떤 플랫폼이었나

테코블은 공식 안내문보다 훨씬 가까운 거리에서 크루의 학습과 문제 해결 방식을 보여주던 공간입니다. 같은 우테코 안에서도 누군가는 객체지향과 테스트를 정리했고, 누군가는 Spring/JPA와 트랜잭션을 파고들었고, 또 다른 누군가는 React 렌더링, 이미지 업로드, 데이터베이스 복제, 배포와 운영 이슈를 프로젝트 맥락과 함께 남겼습니다.

그래서 이 블로그는 우테코 크루들이 무엇을 배웠고 어떤 방식으로 설명하려 했는지를 보여주는 학습 아카이브에 가깝습니다.

| 관점 | 설명 |
|---|---|
| 운영 방식 | 기수별 크루들이 작성자 페이지를 가지고 개별 기술 글을 발행하던 구조 |
| 탐색 방식 | 최신 글 목록, 태그, 작성자, RSS, sitemap을 통해 글을 계속 따라가게 설계된 정적 블로그 |
| 글의 결 | 개념 요약, 프로젝트 문제 해결, 코드 리뷰 포인트, 설계 회고가 한데 섞여 있음 |
| 읽는 재미 | 기수별로 관심 주제가 어떻게 이동하는지, 같은 키워드가 어떤 맥락에서 다시 등장하는지 비교하기 좋음 |
