# 발견 학습 설계하기 — 답을 먼저 주지 않는 환경

[교육 철학](/education/philosophy#발견-학습)에서 **왜** 답을 먼저 주지 않는지를 봤다면, 이 페이지는 그 원칙을 **여러분의 미션·수업·코드 리뷰에 어떻게 심는가**를 다룹니다. 우테코가 실제로 건 사례를 보고, 여러분의 환경에 맞게 설계하도록 돕는 LLM 스킬로 이어집니다.

## 한 줄 원리

**예측(Predict) → 관찰(Observe) → 설명(Explain).** 정답을 주입하지 않고, 배우는 사람이 먼저 예측하고 판단하고 설명한 뒤에야 정답과 마주치게 합니다. 핵심은 순서를 뒤집지 않는 것입니다 — 강의를 먼저 하면 "이해한 척"이 생깁니다. 교차 증거는 [POE 발견 학습 패턴](/education/insights/poe-discovery-learning)에서 확인할 수 있습니다.

설계할 때 빠지기 쉬운 함정은 하나입니다 — 설명을 먼저 하고 과제를 나중에 내는 "강의 → 실습" 순서. POE는 순서가 뒤집혀야 작동합니다.

## 여러분 환경에 설계하기 — LLM 스킬

<Callout type="tip">
**설계용 LLM 스킬을 GitHub에 공개합니다.** [발견 학습 설계 스킬 저장소](https://github.com/woowacourse/llm-skills)를 받아 여러분이 쓰는 LLM(ChatGPT·Claude 등)에 붙여넣으면, 여러분의 미션·수업·리뷰 맥락을 입력으로 받아 **예측 과제 → 공개 시점 → 비교 회고**까지 POE 사이클 한 벌을 설계해 줍니다.
</Callout>

스킬은 다음을 묻고 채워 줍니다 — 어떤 개념에 인지적 불일치를 만들 것인가, 무엇을 예측 산출물(해설지·에세이·리뷰 글)로 받을 것인가, 정답을 언제 공개할 것인가, 비교 회고를 어떻게 배치할 것인가.

### 프롬프트 예시 — 스킬 없이 바로 써보기

저장소를 붙이기 전에, 아래 프롬프트를 복사해 `{중괄호}`만 여러분 맥락으로 바꿔 LLM(Claude·ChatGPT 등)에 넣어도 됩니다. Anthropic Opus 4.8 프롬프트 엔지니어링 가이드의 권장 — **역할 부여 · 섹션 구조화 · 명시적 제약 · 먼저 오개념을 짚게 하는 추론 단계 · 예시(멀티샷) · 출력 형식 고정** — 을 따랐습니다. 구획은 사람이 복사·편집하기 쉽도록 XML 태그 대신 마크다운 헤더(`#`·`##`)로 나눴습니다.

```text
당신은 우아한테크코스의 발견 학습(POE) 설계를 돕는 교육 코치입니다.
발견 학습의 핵심은 예측(Predict) → 관찰(Observe) → 설명(Explain) 순서이며,
이 순서를 절대 뒤집지 않습니다 — 정답·강의를 먼저 주면 "이해한 척"이 생기기 때문입니다.

<배경>
- 학습자: {예: 백엔드 레벨2 크루 16명}
- 다룰 개념: {예: 자바 비동기·동시성 — 말로는 아는데 코드로는 못 쓰는 개념}
- 형식·시간: {예: 90분 수업 1회}
- 내가 평소 쓰던 방식: {예: 강의 먼저, 실습 나중}
</배경>

<설계_원칙>
1. 정답·강의는 학습자가 예측·판단·설명을 먼저 산출한 뒤에야 공개한다.
2. 예측 산출물은 채점 대상이 아니라 "관찰 대상"이다 — 머릿속 모델의 허점을 드러내는 게 목적.
3. 비교 회고에서 "내 예측 vs 실제"의 간극을 학습자가 스스로 언어화하게 한다.
</설계_원칙>

<할_일>
먼저 이 개념에서 학습자가 가장 흔히 빠지는 오개념(인지적 불일치 지점)을 1~2개 짚어라.
그다음 그 지점을 정확히 건드리는 POE 사이클 한 벌을 설계하라.
</할_일>

<출력_형식>
## 겨냥할 오개념
- ...
## 1. 예측 (Predict)
- 예측 과제 · 산출물(관찰 대상):
## 2. 관찰 (Observe)
- 정답·실제와 마주치는 방법 · 공개 시점:
## 3. 설명 (Explain)
- 비교 회고 질문 · 코치가 던질 되묻는 질문:
## 설계 의도
- 왜 이 오개념을 겨냥했고 왜 이 순서인가:
</출력_형식>

<예시>
우테코 비동기 수업: 강의 대신 "비동기 퀴즈 해설지를 먼저 쓰게"(예측) 해
설명 능력 자체를 관찰 대상으로 삼고, 실제 실행 결과와 마주친 뒤(관찰)
"내 해설과 실제가 어디서 갈렸나"를 회고하게 했다(설명).
</예시>
```
