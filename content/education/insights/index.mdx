# 검증된 패턴

교육 현장에서 반복적으로 등장하는 문제와, 여러 실험 로그에서 독립적으로 검증된 해결 패턴을 정리합니다.
각 패턴은 **문제 → 근거 로그 → 핵심 원칙 → 적용 가이드** 구조로 기술합니다.
개별 실험은 로그에, 여러 로그에서 반복 검증된 패턴은 여기에, 더 일반화된 원칙은 교육 철학·커리큘럼에 자리잡습니다.
