# 검증된 패턴

교육 현장에서 반복해서 마주치는 문제와, 여러 실험 로그에서 따로따로 검증된 해결 패턴을 모았습니다.
각 패턴은 **문제 → 근거 로그 → 핵심 원칙 → 적용 가이드** 순서로 적었습니다.
개별 실험은 로그에 두고, 여러 로그에서 반복해 검증된 패턴은 여기에 묶고, 더 일반화된 원칙은 교육 철학·커리큘럼으로 올립니다.
