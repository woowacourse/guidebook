# 원정대: 송곳 같은 강점 만들기

<Callout>
**대상**: 크루의 자기주도 학습 활동을 설계하려는 코치

**맥락**: 레벨 1 · 기본기 격차가 드러나는 시점

**핵심 질문**: 목표가 모호한 스터디를 측정 가능한 강점 만들기 활동으로 어떻게 바꿀까?
</Callout>

## 배경과 문제

레벨 1 크루들이 미션을 수행하면서 기본기의 격차가 드러났습니다. JavaScript 동작 원리, 설계 원칙, 테스트 습관 등 크루마다 부족한 영역이 다르고, 일괄적인 강의만으로는 각자의 약점을 채우기 어려웠습니다.

기존 스터디 방식은 "책 읽기"나 "알고리즘 풀기"처럼 목표가 모호하고 측정이 어려워, 활동이 흐지부지되는 경우가 많았습니다.

## 설계

### 핵심 목표

팀 프로젝트나 단순 스터디가 아닌, **각자가 송곳 같은 강점 1개를 만들기 위해 동료와 함께 지식을 탐험하는 활동**으로 설계했습니다.

핵심은 두 가지입니다.

- **탐험**: 주제나 목적을 달성하기 위해 동료와 함께 파고드는 방식
- **공유**: 각자가 전문가가 된 뒤, 다른 크루들에게 전파하는 구조

### 주제 설계 원칙

좋은 주제가 갖춰야 할 4가지 조건을 정했습니다.

| 조건 | 설명 |
|------|------|
| 작다 | 한 문장으로 설명할 수 있다 |
| 깊다 | 4주 이상 계속 파고들 수 있다 |
| 실행 가능하다 | 미션, 예제, 학습 기록 등으로 꾸준히 실험할 수 있다 |
| 측정 가능하다 | 좋아졌는지 숫자나 사례로 확인할 수 있다 |

"모던 자바스크립트 Deep Dive 다 읽기", "알고리즘 잘하게 되기"처럼 맹목적이거나 측정이 모호한 주제는 허용하지 않았습니다.

### 주제 제안

코치가 제안한 주제 카테고리입니다. 크루는 이 중에서 선택하거나, 직접 주제를 만들어 코치 승인을 받을 수 있습니다.

| 카테고리 | 주제 예시 | 측정 예시 |
|----------|-----------|-----------|
| 언어 기본기 (JS/TS) | JS 코드 동작 원리 이해: 실행 컨텍스트·스코프·클로저로 코드 흐름 설명하기 | 미션 코드의 복잡한 흐름을 실행 컨텍스트 다이어그램으로 설명한 문서 3건 |
| 언어 기본기 (JS/TS) | 배열/객체 메서드 활용하기 | 미션에서 for 문 사용 0건, 비교 문서 3건 |
| 언어 기본기 (JS/TS) | 프로토타입 체인 이해 | class → 프로토타입 기반 재작성 비교 문서 3건 |
| 언어 기본기 (JS/TS) | 디버깅 프로토콜 수립 | 나만의 프로토콜에 따라 처리한 버그 리포트 3건 |
| 설계와 원칙 | 읽기 쉬운 코드 원칙 적용하기 | 책에서 학습한 원칙을 미션에 3개 이상 적용 |
| 설계와 원칙 | SOLID에 따라 변경에 유연한 코드 만들기 | SOLID 위반 → 개선 사례 5건 |
| 테스트와 리팩터링 | TDD로 사고 익히기 | TDD 과정 회고 작성, 리뷰어 피드백 |

### 활동 구조

3~5명으로 팀을 구성하고, 원정대장이 활동을 리딩합니다.

| 단계 | 내용 |
|------|------|
| 팀 구성 | 3~5명, 원정대장 선정 |
| 주제 확정 | 각자 강화할 송곳 1개 이상 선정 |
| 실행 | 매주 정한 방식으로 실습/실험/정리 |
| 기록 | 시도/결과/다음 개선점 정리 |
| 공유 | 1차, 중간, 최종 공유 |

### 공유 설계

공유는 발표가 아니라 **전이**입니다. "내가 잘했다"를 보여주는 시간이 아니라, 다른 크루가 내 방법을 바로 따라 할 수 있게 만드는 시간입니다.

공유 시 필요한 3가지:

1. 무엇을 시도했는가?
2. 어떤 결과가 나왔는가?
3. 다른 사람이 그대로 흡수할 수 있는 실습 활동 (라이브 코딩, 워크숍 등)

### 활동 가이드: 야생학습과 애자일

크루들에게 두 가지 원칙을 안내했습니다.

- **야생학습**: 순차적 학습이 아니라, 목적을 명확히 하고 책·웹·사람·AI 등 모든 자원을 활용하여 학습한다.
- **애자일**: 완벽한 계획을 세우지 않고, 핵심을 바로 찌른 뒤 피드백을 받으며 나아간다.

활동 전 반드시 답해야 할 3가지 질문:

1. **측정**: 공유회 때 어떤 상태가 되면 좋을까? 어떤 결과물이 나와야 할까?
2. **센터 찾기**: 그것을 달성하기 위해 가장 중요한 핵심 활동은 무엇인가?
3. **자원 찾기**: 어떤 자원을 활용할 수 있을까?
