# 크루 성장 여정 페이지 Implementation Plan

> **For agentic workers:** 이 저장소엔 React 컴포넌트 단위 테스트 러너가 없다. 검증은 dev 서버 육안 확인 + `npm run lint:tone`(문체)로 한다. 각 태스크 끝에 검증 스텝을 둔다.

**Goal:** 행성이 성장 아크(레벨 0→5)를 한눈에 보여주는 새 전용 페이지 `/education/journey`를 만든다.

**Architecture:** 6단계 데이터를 `content/growth-arc.ts` 한 곳에 두고, `CrewGrowth` 컴포넌트가 히어로(반응형 성장 길)와 서사 섹션을 그 배열 하나로 렌더링한다. MDX 페이지가 컴포넌트를 얹고, `_meta.ts`·`mdx-components.tsx`·`updates.ts`에 배선한다.

**Tech Stack:** Next.js App Router + Nextra 4, React(서버 컴포넌트 가능 — 상태 없음), CSS Module, 기존 `CrewJourney` 패턴.

## Global Constraints

- 본문·UI 문구는 전부 **합니다체**. `npm run lint:tone` 통과. (한다체·해요체 금지)
- 캐릭터는 `public/images/characters/` 기존 18종에서만 고른다. 신규 제작 금지.
- 라인아트 PNG는 다크모드에서 `:global(.dark) .pose { filter: invert(1) }`.
- 새 MDX 추가 시 `_meta.ts` + `content/updates.ts` 동시 갱신(CLAUDE.md 필수).
- 데이터는 단일 원천(`growth-arc.ts`) — 문구를 컴포넌트/MDX에 중복 하드코딩 금지.
- 커밋은 내 변경만 의미 단위로. 자동 커밋 훅이 병렬 WIP(`cards-fixed.png` 등)를 섞지 않게, 내 파일만 명시적으로 `git add`.
