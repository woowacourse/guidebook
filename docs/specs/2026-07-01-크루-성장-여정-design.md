# 크루 성장 여정 페이지 — 설계 (spec)

- 날짜: 2026-07-01
- 상태: 승인됨 (브레인스토밍 완료)
- 요청: 교육 섹션에 "크루로서 어떻게 성장해나가는지" 스토리가 느껴지는 페이지. 행성이 일러스트로 작은 행성이가 커나가는 모습을, 특히 커리큘럼과 함께 한눈에 먼저 보이게.

## 목표 (성공 기준)

1. **한눈에** — 페이지를 열면 레벨 0→5 성장 곡선이 스크롤 전에 파악된다.
2. **스토리** — 작은 행성이(호기심)가 빛나는 개발자(축하)로 커나가는 서사가 느껴진다.
3. **커리큘럼과 함께** — 각 단계가 실제 커리큘럼/미션 근거로 이어진다.
4. **모바일 적합** — 세로가 기본, 데스크톱에서 가로로 펴지는 반응형(대각선·억지 리플로 금지).

## 결정 사항 (브레인스토밍)

- **배치**: 새 전용 페이지. 사이드바 '이해하기' 그룹, `철학 → 성장 여정 → 커리큘럼` 순서.
- **트랙 범위**: 하나의 보편 아크(레벨 0~5 공통 골격). 트랙별 분기 없음.
- **히어로 레이아웃**: 반응형 성장 길 — 데스크톱 ≥880px 가로 리본(한 줄), 모바일 <880px 세로 척추. 캐릭터가 진행 방향으로 실제로 커짐.

## 구현 대상

### 1) 데이터 — `content/growth-arc.ts` (신규, 단일 원천)
6단계 배열. 히어로와 서사 섹션이 이 하나를 공유한다.

```ts
export interface GrowthStage {
  level: string        // '레벨 0' ~ '레벨 5'
  stage: string        // 단계 한 단어 (온보딩·기초·중급·협업·심화·취업)
  title: string        // 이 단계의 한 줄 제목
  glance: string       // 히어로 캡션 (짧게)
  story: string        // 서사 2~3문장 (합니다체)
  pose: string         // 파일명 (확장자 제외) — public/images/characters
  size: number         // 히어로에서 렌더 폭(px) — 단계마다 커짐
  links?: { label: string; href: string }[]  // 커리큘럼 근거 (실재하는 것만)
}
```

포즈·크기·서사 매핑:

| 레벨 | 단계 | 포즈 | size | 서사 방향 |
|---|---|---|---|---|
| 0 | 온보딩 | 행성이-호기심 | 44 | 연극으로 서로를 먼저 안다 (심리적 안정감) |
| 1 | 기초 | 행성이-코딩 | 52 | 손이 코드에 익는다 (테스트·리팩터링) |
| 2 | 중급 | 행성이-운동 | 60 | 반복으로 근육을 만든다 (프레임워크·설계) |
| 3 | 협업 | 행성이-회의 | 70 | 팀으로 함께 짓고 배포한다 |
| 4 | 심화 | 행성이-과열 | 80 | 깊이 파고들다 부딪힌다 (레거시·성능·아키텍처) |
| 5 | 취업 | 행성이-축하 | 96 | 빛나는 개발자로 (이력서·면접·리크루팅데이) |

근거 링크 후보(실재 확인 필요): `/education/tools/drama-onboarding-kit`, `/education/curriculum`, `/education/logs/fe-lotto-2026-prs`, `/education/logs/fe-movie-review-2026-prs`, `/education/philosophy`.

### 2) 컴포넌트 — `components/CrewGrowth.tsx` + `components/CrewGrowth.module.css` (신규)
- **히어로 (한눈에)**: 데스크톱 가로 리본(6정거장, 연결선, 왼→오른쪽으로 커지는 포즈, 양끝 캡션 "작은 별에서 → 빛나는 개발자로"). 모바일 세로 척추(위→아래로 커짐). 기존 `CrewJourney`의 데스크톱/모바일 폴백 구조를 따른다.
- **서사 섹션 (스토리)**: 히어로 아래 6블록. 각 블록 = 큰 포즈 + 레벨/단계 + story + 근거 링크.
- 다크모드: 라인아트 PNG에 `:global(.dark) .pose { filter: invert(1) }` (CrewJourney.module.css:107 패턴).
- 접근성: 히어로 컨테이너 `role="img"` + `aria-label`(전체 여정 요약), 장식 노드 `aria-hidden`, 서사 섹션은 실제 텍스트로 읽힘.

### 3) 페이지 — `content/education/journey.mdx` (신규)
- 짧은 도입(합니다체) + `<CrewGrowth />` + 커리큘럼/철학으로 잇는 마무리 카드.
- frontmatter/테마는 philosophy.mdx 등 형제 페이지와 정합.

### 4) 배선 (CLAUDE.md 필수)
- `mdx-components.tsx` — import + register `CrewGrowth`.
- `content/education/_meta.ts` — `journey: '🌱 성장 여정'` 를 `philosophy` 다음, `curriculum` 앞에 삽입.
- `content/updates.ts` — 배열 맨 위에 새 Update 항목 1개(`href: '/education/journey'`).
