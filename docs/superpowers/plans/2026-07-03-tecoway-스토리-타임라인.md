# TecoWay 스토리 타임라인 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** TecoWay의 긴 서사 단락을 "도착 → 동료와 함께 → 빛나는 별로 떠남" 3단계 가로 타임라인으로 재구성해 가독성을 높이고 크루 중심 스토리를 스캔 가능하게 만든다.

**Architecture:** `components/TecoWay.tsx`/`.module.css`만 수정한다. `STEPS` 배열(3개)을 flex 가로 타임라인으로 렌더하고, 마커 3개 중 앞 둘은 점(dot), 마지막(③ 떠남)은 `행성이-반짝` 캐릭터로 둔다. 마커 슬롯 높이를 고정해 단일 수평 연결선이 세 마커 중심을 통과하게 한다. 긴 `<p>` 서사와 상단 히어로 캐릭터는 제거하고, 735는 캡션 한 줄로 옮겨 throughline을 유지한다. 모바일은 세로 스택.

**Tech Stack:** Next.js 15 App Router, Nextra 4, React 19, CSS Modules, TypeScript 5.7, `next/link`. 컴포넌트 테스트 프레임워크 없음 — 검증은 라이브 dev 서버 SSR + 정적 `lint:mobile` + 헤드리스 스크린샷(컨트롤러).

## Global Constraints

- **카피 규칙:** 사용자 노출 본문은 합니다체. em-dash(`—`, U+2014) 금지 — 쉼표·마침표로 대체. (주석의 화살표/기호는 무관.) 비유는 "빛나는 별이 되어"만 유지, 나머지는 구체어(크루·동료·미션·페어·코드리뷰).
- **단일 원천 + throughline:** 크루 수는 `crewCount`(`content/crew-voices.ts`) import. 735 하드코딩 금지. 캡션이 735를 소개해 다운스트림 CrewVoiceMap("앞서 본 735명")·CrewJourney("그 735명")의 지시 대상을 유지한다. 735 언급 제거는 결함.
- **스타일 관계:** `.section`·`.heading`(+`:global(.dark)`) 토큰은 형제 `components/CrewJourney.module.css`와 동일 값 유지. 캐릭터 다크 반전은 CrewJourney `.planet` 패턴(`filter: invert(1)` + `mix-blend-mode: screen`), glow는 라이트 `rgba(255,219,170,0.5)`/다크 `rgba(255,230,195,0.16)`.
- **모바일 안전:** glow·캐릭터 고정폭 금지 — glow `min(160px, 45vw)`, `.pose` `max-width:100%`. 데스크톱 가로, 모바일(<=680px) 세로 스택, 가로 오버플로우 0. (`lint:mobile`에서 `TecoWay.module.css` 신규 findings 0.)

- **커밋 격리:** Stop 훅이 `git add -A`로 쓸어 담고 병렬 세션 WIP가 main에 올라온다. 정확히 2개 파일(`components/TecoWay.tsx`, `components/TecoWay.module.css`)만 `git add`. `git add -A`/`.` 금지. 커밋 직전 `git status --short`로 확인, 섞이면 `git restore --staged <파일>`.

- [ ] **Step 1: `components/TecoWay.tsx` 전체 교체**

```tsx
import Link from 'next/link'
import styles from './TecoWay.module.css'
import { Eyebrow } from './Eyebrow'
import { crewCount } from '../content/crew-voices'

/**
 * TecoWay: 랜딩에서 Hero 다음에 오는 '우테코의 10개월' 선언.
 * 한 크루의 여정을 3단계 타임라인으로: 혼자 도착, 동료와 함께 성장, 빛나는 별이 되어 떠남.
 * 마지막 단계 마커에만 행성이(반짝)를 두어 '빛나는 별'을 그 지점에서 회수한다.
 * 735 캡션은 다운스트림 별자리('앞서 본 735')/행선지('그 735')의 지시 대상을 유지한다(crewCount 단일 원천).
 * 성장 여정 전체(레벨 0~5)는 /education/journey(CrewGrowth)로 연결한다.
 */
const STEPS = [
  { label: '도착', text: '혼자, 우테코에서 시작합니다' },
  { label: '동료와 함께', text: '진짜 미션을 페어와 코드리뷰로 풀며 자랍니다' },
  { label: '떠남', text: '빛나는 별이 되어 소프트웨어 생태계로', star: true },
]

export function TecoWay() {
  return (
    <section className={styles.section} aria-label="우테코의 10개월, 한 크루가 빛나는 별이 되기까지">
      <Eyebrow>우테코의 10개월</Eyebrow>
      <h2 className={styles.heading}>한 크루가, 동료와 함께 빛나는 별이 되어 떠납니다</h2>

      <ol className={styles.timeline}>
        {STEPS.map((s) => (
          <li key={s.label} className={styles.step}>
            <span className={styles.marker} aria-hidden="true">
              {s.star ? (
                <>
                  <span className={styles.glow} />
                  <img className={styles.pose} src="/images/characters/행성이-반짝.png" alt="" width={72} />
                </>
              ) : (
                <span className={styles.dot} />
              )}
            </span>
            <span className={styles.stepLabel}>{s.label}</span>
            <span className={styles.stepText}>{s.text}</span>
          </li>
        ))}
      </ol>

      <p className={styles.caption}>
        지금까지 이 길을 지난 크루 <strong>{crewCount}명</strong>.
      </p>

      <Link className={styles.journeyLink} href="/education/journey">
        10개월, 어떻게 자라는지 →
      </Link>
    </section>
  )
}
```
