# "시작하기" 페이지 + 두 모드 IA 설계

- 작성일: 2026-06-16
- 상태: 설계 확정(사용자 리뷰 대기)
- 범위: `content/education/` 정보구조 개편 + 신규 "시작하기" 페이지

---

## 1. 목표와 배경

### 문제

우테코 공식문서는 콘텐츠가 **저자의 멘탈 모델**(추상→구체, "아래에서 위로 승격되는 파이프라인")로만 정렬돼 있다. 이 순서는 "이 지식이 어떻게 만들어졌는가"를 설명하지만, 독자의 가장 흔한 질문 **"나는 무엇을 바꾸고 싶은데, 어디서 시작하지?"** 에는 답하지 않는다. 그 결과 문서가 "기능적인 위키"처럼 느껴지고 "공식문서"의 큐레이션된 느낌이 약하다.

### 발견 — 두 개의 독자 모드

이 문서에는 두 모드가 공존한다:

- **① 이해하기(Understand)** — "8년째 운영 중인 10개월 교육을, 철학부터 커리큘럼 구현까지 어떻게 설계·반영했나"를 보고 평가하려는 독자. 추상→구체의 서사로 읽는다.
- **② 만들기(Build)** — "스스로 자라는 환경을 직접 경험하고 만들려는" 독자. 행동 중심으로 읽는다.

현재 사이드바는 ①(이해) 순서로만 정렬돼 있어 ②(만들기)의 입구가 비어 있다. 이 설계는 **②의 입구("시작하기")를 신설하고, 두 모드를 명시적으로 드러내도록 IA를 개편**한다.

### 두 가지 산출물

1. **IA 개편** — 개요를 "두 개의 문"을 제시하는 서사형 랜딩으로 재작성하고, 사이드바를 의미 그룹(만들기 / 이해하기 / 원재료)으로 묶는다.
2. **"시작하기" 페이지** — ②(만들기) 모드의 진입점. 활성화 중심으로, 독자가 끝까지 읽으면 **"이번 주에 시도할 가장 작은 변화 행동 1개"**를 손에 쥐고 나간다.

## 2. 확정된 설계 결정

| 축 | 결정 | 근거 |
|----|------|------|
| 1순위 독자 | "사람들이 스스로 자라는 환경을 만들고 싶은 사람" (운영자+팀리더+멘토를 *직무*로 묶음) | 직함으로 나누면 갈라지고, 하려는 일로 묶으면 하나로 모인다. 콘텐츠 무게중심이 '환경 설계자'에 있음 |
| 독자 구조 | 공유 척추 + 가벼운 분기 | 본문 줄기는 하나, 페르소나는 '레버 크기·깊이'만 분기 |
| 결과물(야망) | 활성화 우선 — "이번 주 작은 행동 1개" | 도입 성공의 최대 변수는 빠른 첫 성공(quick win) |
| 페이지 흐름 | 5분 이해 → 오늘의 작은 변화 1개 → 다음 문 | 이해는 행동을 정당화할 만큼만 |
| 페이지 위치 | `/education` 사이드바 "만들기" 그룹, 라벨 "🚀 시작하기", 슬러그 `/education/start` | 교육에 들어온 사람이 만나는 만들기 입구. 라벨은 간결하게('변화'의 약속은 본문에서) |
| IA 배치 | 개요 두 문 + 사이드바 3그룹 (안 A) | 서사+위계로 "공식문서다움" 회복, 두 모드를 첫 화면에서 선택 |
| 홈/탑내비 | 변경하지 않음 | 이번 범위는 `/education` 내부에 한정 |

## 3. IA 개편 상세

### 3.1 사이드바 그룹화 — `content/education/_meta.ts`

목표 순서(위→아래):

```
📖 개요                      ← 허브(index)
── 만들기 ──────────────      (separator)
🚀 시작하기                   ← 신규
── 교육 모델 이해하기 ──        (separator)
🎯 교육 철학
🗺️ 커리큘럼
⬆️ 검증된 패턴 (N)
── 원재료 ──────────────      (separator)
⬆️ 실험 로그 (N)
🛠️ 검증된 도구               ← hidden 해제
```

- 기존 `index`/`philosophy`/`curriculum`/`insights`/`logs`의 키·계산 로직(`insightsCount`, `logs.length`)은 **건드리지 않는다**.
- `tools`의 `display: 'hidden'`을 제거해 "원재료" 그룹에 노출.
- `conversations`/`assessment`/`failed-experiments`/`operations`는 hidden 유지(렌더되지 않으므로 그룹 경계에 영향 없음).
- **⚠️ 구현 주의:** 이 저장소의 어떤 `_meta.ts`도 아직 `separator`를 쓰지 않는다(grep 결과 0건). Nextra 4 표준은 `{ type: 'separator', title: '만들기' }` 형태이나, **렌더링을 실제로 확인할 것.** 그룹 헤더가 의도대로 표시되지 않으면 **폴백:** separator 없이 순서만 위와 같이 두고, 두 모드 구분은 개요의 "두 문"에 의존한다.

### 3.2 개요 재작성 — `content/education/index.mdx`

현재: H1 "교육" + 4카드 리스트 + "콘텐츠는 아래에서 위로 승격됩니다" 설명.

변경: **서사 리드 → 두 문 → 전체 지도** 3단 구성.

1. **서사 리드(산문 2~3문장)** — 예: "우아한테크코스는 8년째 10개월짜리 교육을 굴려 왔습니다. 이 문서는 두 길로 읽을 수 있습니다 — 그 설계를 **이해**하거나, 당신의 자리에서 직접 **시작**하거나."
2. **두 문 (`CardGrid columns={2}`)**:
   - **① 모델 이해하기** → `/education/philosophy` — "철학부터 커리큘럼 구현까지, 8년의 설계를 추상에서 구체로"
   - **② 직접 만들기** → `/education/start` — "이번 주 가장 작은 변화 1개부터, 스스로 자라는 환경을 직접"
3. **전체 지도(기존 자산 보존)** — 기존 4카드 리스트(`CardGrid variant="list"`)와 "아래에서 위로 승격" 설명을 그 아래 압축 유지. 두 문이 히어로, 지도는 보조.

### 4.3 카피 초안

**① Hero**
- H1: `시작하기 — 이번 주, 가장 작은 변화 하나`
- 인트로: "동료가 한 명이든 백 명이든, 사람이 스스로 자라는 환경을 만드는 원리는 같습니다. 이 페이지를 끝까지 읽으면 **이번 주에 당신이 시도할 가장 작은 변화 행동 1개**를 손에 쥐고 나갑니다. (바로 행동만 보고 싶다면 아래 직행 링크를 누르세요.)"

**② 지금 바로 (`Callout type="tip"`)**
- "**5분 이해 → 오늘의 변화 1개 → 다음 문.** 바로 자기 행동으로 가려면:"
- 앵커 4개: `코드·사람을 마주하는 멘토라면 →`(#mentor) / `팀을 운영하는 팀리더라면 →`(#lead) / `환경을 설계하는 운영자라면 →`(#operator) / `아직 직무가 없다면 →`(#anyone)

**③ 5분 이해**
- 헤드라인: "정답을 떠먹여 주지 않고, 사람이 스스로 자라는 환경을 설계한다"
- 산문(요지): 코치(가르치는 사람)는 답이 아니라 기준·환경을 깔고, 크루(배우는 사람)는 자기 학습을 직접 진단·설계하는 주체다. 그래서 먼저 예측하게 하고(발견 학습), 무거운 주제는 나눠 쌓고(스캐폴딩), 질문하는 회고로 협업을 '구조'로 깐다. 이 원칙들은 신념이 아니라 매주 실험으로 증명돼 남은 가설이다. 우테코 고유어는 첫 등장 1회만 괄호 주석("크루=배우는 사람").
- 핵심개념 4카드(`CardGrid columns={2}`):
  | 카드 | 한 줄 | 링크 |
  |------|-------|------|
  | 자기주도 학습 | 배우는 사람이 학습의 주체 | `/education/insights/self-diagnostic-framework` |
  | 발견 학습 (예측→관찰→설명) | 답보다 예측을 먼저 | `/education/insights/poe-discovery-learning` |
  | 함께 성장하는 문화 | 협업은 분위기가 아니라 구조 | `/education/insights/argumentation-based-learning` |
  | 점진적 스캐폴딩 | 한 번에 안 쏟고 발판을 댄다 | `/education/insights/progressive-scaffolding` |
- 섹션 끝 한 문장: "줄기는 하나(스스로 자라는 환경), 손잡이 크기만 다릅니다 — 운영자=큰 레버, 팀리더=중간 레버, 멘토=작은 레버."

**④ 오늘의 작은 변화 1개 (심장)**
- 자가 라우팅 한 줄: "코드와 사람을 마주하면 멘토 / 팀을 운영하면 팀리더 / 커리큘럼·미션을 설계하면 운영자 / 아직 권한이 없으면 누구나 — **자기 한 장만** 고르세요."
- `CardGrid columns={2}` (2×2), **레버 작은 순**:

  각 카드 공통: 제목(명령형) · 첫 단계 1줄 인라인 · 이미 채워진 약속 문장 1줄 · 보조 링크 · 소요(분).

  1. **누구나 (권한 0) · 20분** — `id=anyone`
     - 제목: "내가 최근 남긴 코멘트 1줄을 5가지 기준으로 다시 쓰기"
     - 첫 단계: 내가 쓴 피드백 한 줄을 구체성·균형성·실행가능성·관찰기반·성장지향성 5기준으로 점수화 → 가장 낮은 1개를 Before/After로 고쳐 쓴다.
     - 약속: "→ 이번 주 약속: 다음에 글을 남길 때 이 다시 쓴 버전처럼 쓴다."
     - 1차 링크: `/education/logs/feedback-refactoring` · 보조: `/education/insights/self-diagnostic-framework`
  2. **멘토 (작은 레버) · 15분** — `id=mentor`
     - 제목: "다음 리뷰 코멘트 1줄을 정답 대신 질문으로 바꾸기"
     - 첫 단계: 정답 적으려던 코멘트를 멈추고 "왜 이렇게 했나요?" 한 줄로 바꾼다.
     - 약속: "→ 이번 주 약속: 다음 1:1에서 OO에게 정답 대신 질문 1줄을 던진다."
     - 링크: `/education/insights/argumentation-based-learning` (라벨: "검증된 패턴에서 더 보기 →")
  3. **팀리더 (중간 레버) · 20분** — `id=lead`
     - 제목: "다음 회고 1회만 형식을 바꿔보기 (10점 척도 점수화)"
     - 첫 단계: '10점 척도 점수화' 형식으로, 추상 감상 1개에 0~10점 + "왜 그 점수?" 의무 코멘트.
     - 약속: "→ 이번 주 약속: 이번 회고는 점수화 형식으로만 진행한다."
     - 링크: `/education/tools/retrospective-format-kit` (라벨: "이 도구는 검증된 도구 모음의 일부입니다 →")
  4. **운영자 (큰 레버) · 20분 · `운영 환경 필요` 라벨** — `id=operator`
     - 제목: "미션 1개의 최근 PR 3건만 웹에서 열어 골격 vs 사라진 층 메모하기"
     - 첫 단계: CLI 없이 GitHub 웹에서 최근 PR 3건 본문만 열어, 영구 골격 1개 + 새로 들어오거나 사라진 층 1개를 메모. (권한 저장소 없으면 공개 저장소 아무 미션이나)
     - 약속: "→ 이번 주 약속: 다음 미션 재설계 회의에 이 메모 한 장을 들고 들어가 '무엇을 더 쌓을까'를 묻는다."
     - 링크: `/education/tools/mission-repo-analysis-workflow` (라벨: "검증된 도구 모음의 일부 · 전체 5년치 정량 분석 버전 →")

## 5. 적대적 검증에서 반영한 것 / 잘라낸 것(YAGNI)

- **Mermaid 분기도 삭제** — 분기는 '보여주는 것'이 아니라 '카드를 집는 것'으로 충분. 결정 지점이 둘로 쪼개지면 미로.
- **promise 전용 섹션 삭제** — 메타-약속 중복 제거, intro 직후 Callout 한 곳으로 단일화.
- **페르소나 직행 앵커 추가** — 5분 이해 의무 통과 없이 클릭 1회로 자기 카드 도달.
- **first-action 페르소나당 1개로 압축** — 원안 7개 → 4개. 카드 내부 'A냐 B냐' 재분기 제거.
- **운영자 dry-run 행동 제거** — `/로그승격 dry-run`은 이 저장소 메인테이너 전용 내부 워크플로우라 외부 독자에게 실행 불가.
- **운영자 행동 CLI→웹 다운스케일** — gh api·셸 루프·Python 셋업 마찰 제거.
- **그리드를 레버 작은 순으로 배치** — 권한 작은 독자가 시각 최상단에서 자기 카드를 먼저 만남.
- **"누구나(권한 0)" 카드 신설** — 개인 학습자를 접힌 토글에 숨기지 않고 그리드에 노출.
- **대규모 수치를 본문→Toggle 이동** — 백지 신규자가 "저건 큰 조직 얘기"로 닫지 않게.
