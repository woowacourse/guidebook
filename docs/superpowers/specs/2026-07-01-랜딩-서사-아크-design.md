# 랜딩 서사 아크 완성 — 설계 (spec)

- 날짜: 2026-07-01
- 상태: 승인됨 (브레인스토밍 완료)
- 요청: 랜딩에서 Hero와 "우테코를 넘어 소프트웨어 생태계로"(= `CrewJourney`) 사이에, 우테코가 어떤 곳이고 크루가 어떻게 자라는지를 이야기하고 → 수료하며 남긴 별자리 메시지를 보여주고 → 그 크루들이 생태계로 흘러가는 스토리텔링이 이어지게.
- 관계: `docs/specs/2026-07-01-크루-성장-여정-design.md`(교육 섹션 전용 페이지 `CrewGrowth`)와는 **별개**다. 저건 `/education/journey` 전용 페이지, 이건 랜딩 도입 서사. 이름 충돌을 피하려고 이 섹션은 `TecoWay`로 짓는다(`CrewGrowth`는 그 스펙이 선점).

## 배경 — 현재 랜딩

`content/index.mdx` 현재 순서:

1. `Hero` — "소프트웨어 생태계에 선한 영향력을" (열망)
2. `CrewJourney` — "우테코를 넘어 소프트웨어 생태계로" — 크루 735명의 **행선지**(회사 궤도)
3. `CrewVoiceMap` — "크루들이 가장 많이 남긴 메시지" — 수료 메시지 **별자리**(북두칠성)
4. `EnterDocs` — "이제 여러분에게도" (초대, 3개 문)
5. `BookNote` — 책 발간 예정

문제: Hero(열망)에서 곧바로 크루 행선지로 건너뛴다. **우테코가 어떤 곳인지, 크루가 어떻게 자라는지**라는 서사의 허리가 비어 있다. 또 흔적(별자리)이 확산(행선지) *뒤에* 놓여, "수료하며 남긴 말 → 그 사람들이 세상으로 퍼짐"이라는 자연스러운 시간 순서와 반대다.

## 목표 (성공 기준)

1. **허리 채우기** — Hero 다음에 "우테코는 어떤 곳이고 어떻게 자라는가"가 짧고 환기적으로 선다.
2. **감정선 완성** — 열망 → 정체성·방법 → 흔적(별자리) → 확산(행선지) → 초대로 이어진다.
3. **735 throughline** — 규모(735)를 한 실로 꿴다: TecoWay가 소개 → 별자리가 "그 735명이 남긴 메시지" → 행선지가 "그 735명이 간 곳".
4. **랜딩다움** — 커리큘럼 전체를 쏟지 않는다(그건 `/education/curriculum` 몫). 짧은 선언으로 끝낸다.

## 결정 사항 (브레인스토밍)

- **범위**: 새 섹션 1개(정체성+성장 합침) + 별자리를 행선지 앞으로 이동.
- **새 섹션 형태**: 원칙 선언(Manifesto) 스타일. 기존 `Claim` 컴포넌트 재사용. 리드 문장 + 성장 방식 3개를 번호 붙여 선언.
- **컴포넌트 이름**: `TecoWay` (조정 가능). `CrewGrowth`는 형제 스펙이 선점했으므로 쓰지 않는다.

## 최종 순서

| # | 컴포넌트 | 서사 역할 | 변경 |
|---|---|---|---|
| 1 | `Hero` | 열망 | 그대로 |
| 2 | **`TecoWay`** (신규) | 정체성 + 방법 | ✨ 신규 |
| 3 | `CrewVoiceMap` | 흔적 (별자리) | 위로 이동 |
| 4 | `CrewJourney` | 확산 (행선지) | 아래로 이동 |
| 5 | `EnterDocs` | 초대 | 그대로 |

## 구현 대상

### 1) 컴포넌트 — `components/TecoWay.tsx` + `TecoWay.module.css` (신규)

- 서버 컴포넌트(상태 없음). 기존 섹션 컴포넌트(`CrewJourney` 등)의 시각 토큰·간격·`Eyebrow` 사용을 따른다.
- 구성: `<Eyebrow>` + 제목(리드) + 리드 보조(규모 문장) + `Claim` 3개.
- `Claim`은 `components/Manifesto.tsx`에서 재사용(`n` prop에 01/02/03).
- 규모 숫자 735는 `crewCount`(`content/crew-voices.ts`) 재사용 — 하드코딩 금지.

**초안 카피** (근거: `philosophy.mdx` 자율 성장 / `curriculum/index.mdx` 10개월·거꾸로 설계 / `crew-voices.ts` crewThemes. 팀 검수로 자유 수정):

- Eyebrow: `우테코라는 곳`
- 제목: `우테코는, 스스로 자라는 개발자를 기르는 곳입니다`
- 리드 보조: `2018년부터 10개월 과정을 굴리며, 지금까지 크루 {crewCount}명이 이곳을 거쳐 갔습니다.`
- Claim 01 **진짜 미션으로 배웁니다** — 강의를 듣는 게 아니라, 손으로 미션을 풀며 익힙니다. (← 실전 프로젝트·미션)
- Claim 02 **페어와 코드리뷰로 함께 자랍니다** — 혼자 빨리 가기보다, 동료와 멀리 갑니다. (← 소프트스킬·협업 / 함께 자란 동료)
- Claim 03 **스스로 '왜'를 묻습니다** — 정답을 받기보다, 자기 근거를 세웁니다. (← 자기주도 학습 / '왜'를 묻는 사고)

> 카피 사실 주의: "무료"는 현재 본문에 없어 단정하지 않는다. "10개월"은 `curriculum/index.mdx`에 근거가 있다. 02의 "함께 자란 동료"는 바로 다음 별자리에서 회수된다(설계 의도).

### 2) 페이지 — `content/index.mdx` (수정)

`<Reveal>`로 감싼 순서로 재배열:

```mdx

<Reveal><TecoWay /></Reveal>
<Reveal><CrewVoiceMap bleed /></Reveal>
<Reveal><CrewJourney /></Reveal>
<Reveal><EnterDocs /></Reveal>
<Reveal><BookNote /></Reveal>
```

### 3) 재배치로 다시 꿰는 카피 (상호참조)

| 파일 | 현재 | 처리 |
|---|---|---|
| `CrewVoiceMap.tsx:114` | "앞서 본 {crewCount}명이 우테코를 수료하며…" | "앞서 본"의 대상이 이제 TecoWay(735 소개)라 **유효** — 유지 |
| `CrewJourney.tsx:50-53` | "이 문서에 담긴 경험과 문화로 자란 크루 {crewCount}명이…" | 별자리 다음에 오므로 연결감 강화: "앞서 별자리를 남긴 그 {crewCount}명이, 지금 이런 회사들에서…" (문구는 검수) |
| `EnterDocs.tsx` 주석 | "Hero → 증거(CrewJourney·CrewVoices)" | 새 순서로 주석만 정정(기능 무관) |

### 4) 배선

- `mdx-components.tsx` — `TecoWay` import + register(`Claim`·`CrewVoiceMap`·`CrewJourney`·`Reveal`은 이미 등록됨).
- `components/index.ts` — `export { TecoWay } from './TecoWay'` 추가.

### 5) 콘텐츠 필수 작업(CLAUDE.md) 해당 여부

- `updates.ts`: **해당 없음** — 신규 문서 페이지가 아니라 랜딩 구조 변경.
- `_meta.ts`: **해당 없음** — 사이드바 항목 변화 없음.
- `logs.ts`: 해당 없음.

## 검증

- `npm run dev` — 데스크톱/모바일에서 육안 확인. 특히: TecoWay가 Hero와 별자리 사이에서 짧게 읽히는지, 별자리 풀블리드(`bleed`)와 행선지 궤도→칩 폴백이 순서 바뀐 뒤에도 정상인지.
- 다크모드에서 TecoWay 텍스트/`Claim` 대비 확인.
- `npm run lint:tone` — TecoWay 본문 합니다체 통과.
- 735 throughline 3곳(TecoWay 리드 · 별자리 "앞서 본 735" · 행선지 "그 735")이 실제로 이어지는지 눈으로 확인.

## 범위 밖 (YAGNI)

- 별자리(`CrewVoiceMap`)·행선지(`CrewJourney`) 내부 로직/비주얼 변경 — 위치 이동과 상호참조 카피만 손댄다.
- 교육 섹션 `CrewGrowth`/`/education/journey`(형제 스펙) — 이 작업에서 건드리지 않는다.
- 스크롤 애니메이션 신규(기존 `Reveal`만 사용).
- 신규 일러스트 제작.
