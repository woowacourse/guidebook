# TecoWay 스토리 타임라인 — 설계 (spec)

- 날짜: 2026-07-03
- 상태: 승인됨 (브레인스토밍 완료)
- 요청: TecoWay의 긴 서사 한 단락이 가독성을 떨어뜨린다. 스토리텔링을 타임라인처럼 스캔되는 UI로 바꾸고, 비유를 줄여 "한 크루가 동료들과 함께 빛나는 별이 되어 떠난다"는 구체적 프레이밍으로.
- 선행: `docs/superpowers/specs/2026-07-02-tecoway-별메타포-design.md`(현재 TecoWay = eyebrow + 빛나는 행성이 + 긴 서사 단락 + journey 링크). 이 스펙은 그 **본문을 3단계 타임라인으로 재구성**한다.

## 배경 — 현재 TecoWay

`components/TecoWay.tsx`: `Eyebrow("우테코의 10개월") + 빛나는 행성이(반짝) 히어로 + 4문장 서사 단락 + journey 링크`. 문제: 서사 단락이 길어 스캔이 안 되고, 비유("낯선 별에 내려앉는", "한 단계씩 밝아집니다")가 과하다.

재사용/구분:
- `crewCount = 735`(`content/crew-voices.ts`) — 735 throughline 단일 원천.
- `/education/journey`(CrewGrowth) — 레벨 0~5 커리큘럼 성장 레일(6단계, 행성이 커짐). 이 스펙의 3비트(인간적 아크)와는 granularity·프레이밍이 다르며, TecoWay가 여기로 링크한다.
- 기존 `Timeline` 컴포넌트(dot+line, 세로 docs용)는 랜딩 히어로엔 무거워 **미사용**. TecoWay 안에 경량 커스텀 3단계를 만든다.
- 캐릭터 포즈: `행성이-반짝`(빛나는 별).

## 목표 (성공 기준)

1. **가독성** — 긴 단락을 짧은 라벨 + 한 줄짜리 3단계로 쪼개 스캔된다.
2. **타임라인 느낌** — 연결선으로 이어진 3단계가 시각적으로 여정을 드러낸다.
3. **구체성 > 비유** — 유일하게 유지하는 비유는 "빛나는 별이 되어 떠남"(사용자 승인). 나머지는 크루·동료·미션·코드리뷰라는 구체어로.
4. **크루 시점** — "한 크루가 동료와 함께 빛나는 별이 되어 떠난다" 아크(혼자 시작 → 동료와 함께 → 떠남).
5. **throughline 유지** — 735를 캡션으로 남겨 다운스트림 별자리·행선지의 지시 대상을 보존한다.
6. **중복 회피** — CrewGrowth(6레벨 레일)를 복제하지 않는다. 3비트 인간 아크만, journey로 링크.

## 결정 사항 (브레인스토밍)

- **형태**: 가로 3단계 타임라인(모바일 세로 스택).
- **캐릭터**: 상단 히어로 캐릭터 제거. 타임라인 마커 3개 중 **마지막(③ 떠남)을 빛나는 행성이(반짝)**로, 앞 둘은 점(dot). 캐릭터가 "빛나는 별이 되는" 의미 지점에만 등장.
- **제목**: 크루 중심으로 재프레이밍.

## 구현 대상

### 1) 컴포넌트 — `components/TecoWay.tsx` (수정)

- 긴 서사 `<p>` 제거. 상단 히어로 `.figure`/캐릭터 제거.
- 구조: `<section>` → `<Eyebrow>` + `<h2>` 제목 + 3단계 타임라인(`<ol>`) + 735 캡션(`<p>`) + journey 링크(`next/link`).
- 타임라인: 3개 `<li>`(단계). 각 `<li>` = 마커(점 또는 캐릭터) + 라벨 + 한 줄. ③의 마커는 `/images/characters/행성이-반짝.png`(`alt=""`), ①②는 CSS 점.
- `crewCount`는 캡션에서 사용, `Eyebrow` 유지. `Claim`은 이미 제거됨.

**초안 카피** (합니다체, em-dash 금지. 팀 검수로 자유 수정):

- Eyebrow: `우테코의 10개월`
- 제목(h2): `한 크루가, 동료와 함께 빛나는 별이 되어 떠납니다`
- 3단계:
  - ① 라벨 `도착` / 문구 `혼자, 우테코에서 시작합니다`
  - ② 라벨 `동료와 함께` / 문구 `진짜 미션을 페어와 코드리뷰로 풀며 자랍니다`
  - ③ 라벨 `떠남` / 문구 `빛나는 별이 되어 소프트웨어 생태계로`
- 캡션: `지금까지 이 길을 지난 크루 {crewCount}명.` (735는 `<strong>{crewCount}명</strong>`)
- 링크: `10개월, 어떻게 자라는지 →` → `/education/journey`

### 2) 스타일 — `components/TecoWay.module.css` (수정)

- 기존 `.section`·`.heading`(+다크) 토큰 유지. 긴 서사용 `.lede`·상단 `.figure`/`.glow`/`.pose`는 제거하거나 타임라인용으로 재설계.
- 타임라인:
  - 데스크톱: 가로 3열, 각 열 마커 위/문구 아래, 마커 사이 **연결선**(가는 수평선). 형제 섹션 색 토큰(`rgb(55,53,47)` 계열, 다크 흰색) 사용.
  - 모바일(<=680px): 세로 스택(연결선 수직 또는 생략), 가로 오버플로우 금지.
  - ③ 캐릭터 마커: `max-width:100%`, 다크 라인아트 반전(`:global(.dark) .pose { filter: invert(1) }` 패턴), 은은한 glow는 `min(240px,60vw)` 등 고정폭 금지(정적 린트 통과).
  - 앞 마커(dot): 작은 원, 다크 대비.
- 캡션: 작고 옅은 텍스트. 링크: `text-decoration: none !important`(Nextra hover 밑줄 회피, Card/EnterDocs 패턴).

### 3) 배선 — 변경 없음

`mdx-components.tsx`·`components/index.ts`: TecoWay 이미 등록·export. `_meta.ts`·`updates.ts`·`logs.ts`: 해당 없음.

## 검증

- 라이브 dev 서버 SSR(curl): 제목·3단계 라벨/문구·`735`·journey 링크 렌더. 옛 서사("낯선 별에 내려앉는") 잔재 0.
- 헤드리스 스크린샷(브라우저 잠금 시 독립 chromium)으로 **라이트/다크 + 데스크톱/모바일** 육안 확인: 3단계가 타임라인으로 읽히는지, 모바일 세로 스택이 안 깨지는지, ③ 캐릭터·glow가 다크에서 보이는지, 가로 스크롤 없는지.
- `npm run lint:mobile`: `TecoWay.module.css` 신규 findings 0.
- em-dash: `TecoWay.tsx`/`.module.css` 사용자 노출 카피에 `—` 없음.
- `npx next build`는 실행하지 않음(라이브 dev 서버와 `.next` 공유, 순수 컴포넌트 재구성).
