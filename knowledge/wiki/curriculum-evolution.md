# 커리큘럼의 연도별 진화

우테코 커리큘럼은 **영구 골격을 유지한 채 매년 새 학습 목표를 한 층씩 누적**하는 방식으로 진화한다. 단순 반복이 아니라 누적 학습 모델이다.

## 핵심

같은 미션 저장소(react-payments)를 5년간 추적하면 두 가지 층이 동시에 보인다.

- **영구 골격**: form-handling · 컴포넌트 설계 · 상태 관리 · 재사용성. 2021년부터 매년 50% 이상의 PR이 다루는 불변 핵심.
- **누적 추상화**: 매년 그 위에 새 학습 목표가 더해진다. 기존 것을 버리는 게 아니라 쌓는다. 학습 단위가 "기능이 동작하는가"에서 "시스템 경계를 어떻게 설계하는가"로 한 단계씩 올라간다.

따라서 "연도별 커리큘럼 변화"는 매년 완전히 갈아엎는 이야기가 아니라, **무엇이 골격으로 남고 무엇이 새로 얹혔는가**의 이야기다.

## 연도별 델타 (2021 → 2026)

데이터 신뢰도가 연도마다 다르다. 가장 단단한 출처는 FE 페이먼츠 미션 5년 분석이고, 2021–2024는 그 한 미션 중심의 부분 관측(**sparse**), 2025–2026은 다수 출처로 교차 확인됨(**rich**).

- **2021 (sparse)** — 페이먼츠 미션 개설. Form · Custom Hook · 컴포넌트 분리가 핵심. PR 47개. 학습 골격이 자리잡는 해.
- **2022 (sparse)** — 3단계(라이브러리 배포) 도입. PR 117개로 급증. TypeScript 언급이 19%→44%로 한 번 뛴다.
- **2023 (sparse)** — Storybook이 81%까지 정착. PR 145개로 정점. react-router 비중이 31%로 최고.
- **2024 (sparse)** — 3단계 축소, FE 기본기로 회귀. PR 77개. 곁가지를 쳐내고 핵심에 집중한 해.
- **2025 (rich)** — 기준이 "정상 동작"에서 "에러까지 책임진다"로 상향. testing 28%→94%, error-handling 11%→98% 폭증. PR 본문 평균 길이가 3,154자로 늘며 셀프 리뷰·고민 명시 문화 정착.
- **2026 (rich)** — 페이먼츠 미션 완전 재설계: async 1%→99%, MSW 6%→99%, controlled/uncontrolled 61%→96%. "서버 경계 설계·계약"이 학습 목표가 됨. 동시에 레벨 1에 **AI 협업 미션(Gemini Canvas, 전 트랙 공통)** 신설 — "완벽한 코드보다 동작하는 무언가를 세상에 내놓는 경험". PR 본문 평균 5,911자(2021 대비 2.5배).

## 근거

react-payments 555개 PR(2021–2026) 24개 주제 × 6년 매트릭스에서:

- 영구 핵심(매년 ≥50%): form-handling(81→100%), state-management(51→100%), component-design(47→100%), reusability(45→100%).
- 25→26 신설/폭증: async(1→99%), msw(6→99%) — 미션 재설계의 정량 신호.
- 5년간 비중이 절반으로 준 유일한 주제: styling(40→20%). "CSS 선택은 미션의 본질이 아니다"라는 판단의 누적.

2026-03-03 미션 설계 로그는 코드 품질 중심 커리큘럼에 "빠르게 만들고 배포하는 경험"을 더하려는 의도를 명시한다 — 누적의 또 다른 사례.

## 한계 / 보강 필요

- 다년 추적이 가능한 단단한 출처가 **FE 페이먼츠 미션 하나**에 쏠려 있다. 통합 커리큘럼 서술이 FE 편향될 위험.
- 웹 백엔드(자바 MVC·JDBC 등)·안드로이드의 연도별 추적은 아직 미수집. 동일 방식(저장소 PR 시계열 분석)으로 보강해야 통합 타임라인의 균형이 잡힌다.
