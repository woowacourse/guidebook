자기주도 학습 활동의 주제가 작동하려면 갖춰야 할 4조건. "원정대" 활동에서 코치가 크루의 주제 제안을 승인하는 기준으로 사용했다.

| 조건 | 설명 |
|------|------|
| 작다 | 한 문장으로 설명할 수 있다 |
| 깊다 | 4주 이상 계속 파고들 수 있다 |
| 실행 가능하다 | 미션·예제·학습 기록으로 꾸준히 실험할 수 있다 |
| 측정 가능하다 | 좋아졌는지 숫자나 사례로 확인할 수 있다 |

"모던 자바스크립트 Deep Dive 다 읽기" 같은 책 완독, "알고리즘 잘하게 되기" 같은 추상 목표는 4조건 중 **측정 가능성**에서 탈락한다. 책을 다 읽었다고 강점이 생기는 것이 아니고, "잘하게 되기"는 좋아졌는지를 확인할 방법이 없다.

좋은 주제 예시: "JS 코드 동작 원리 이해 — 실행 컨텍스트로 미션 코드의 복잡한 흐름을 설명한 문서 3건", "for 문 사용 0건 + 배열 메서드 비교 문서 3건", "SOLID 위반 → 개선 사례 5건". 모두 한 문장 + 결과물 개수가 명시된다.

이 4조건은 자기주도 학습뿐 아니라 **모든 학습 활동의 사전 검토용 체크리스트**로 일반화 가능하다. 측정 가능한 결과물을 미리 정하지 않은 학습은 자기주도가 아니라 표류다.
