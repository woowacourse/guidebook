자기주도 학습 활동의 주제가 작동하려면 갖춰야 할 4조건. "원정대" 활동에서 코치가 크루의 주제 제안을 승인하는 기준으로 사용했다.

| 조건 | 설명 |
|------|------|
| 작다 | 한 문장으로 설명할 수 있다 |
| 깊다 | 4주 이상 계속 파고들 수 있다 |
| 실행 가능하다 | 미션·예제·학습 기록으로 꾸준히 실험할 수 있다 |
| 측정 가능하다 | 좋아졌는지 숫자나 사례로 확인할 수 있다 |

"모던 자바스크립트 Deep Dive 다 읽기" 같은 책 완독, "알고리즘 잘하게 되기" 같은 추상 목표는 4조건 중 **측정 가능성**에서 탈락한다. 책을 다 읽었다고 강점이 생기는 것이 아니고, "잘하게 되기"는 좋아졌는지를 확인할 방법이 없다.

좋은 주제 예시: "JS 코드 동작 원리 이해 — 실행 컨텍스트로 미션 코드의 복잡한 흐름을 설명한 문서 3건", "for 문 사용 0건 + 배열 메서드 비교 문서 3건", "SOLID 위반 → 개선 사례 5건". 모두 한 문장 + 결과물 개수가 명시된다.

이 4조건은 자기주도 학습뿐 아니라 **모든 학습 활동의 사전 검토용 체크리스트**로 일반화 가능하다. 측정 가능한 결과물을 미리 정하지 않은 학습은 자기주도가 아니라 표류다.

안드로이드 8기 레벨0(4주 입학 전 과정)에서 같은 4조건이 다른 형태로 확인됐다. 19명 전원에게 학습 계획서를 쓰게 했을 때, 코치는 **나쁜 목표 예시**와 **좋은 목표 예시**를 명시적으로 대비시켰다.

- 나쁜 목표: "Kotlin in Action 완독", "4주 동안 5장 읽기"
- 좋은 목표: "Java와 비교하며 Kotlin이 왜 null-safety를 언어 레벨에서 강제하는지 설명할 수 있다"

전자는 "측정 가능성"에서 탈락한다 — 책을 다 읽었다는 사실이 강점을 만들지 않는다. 후자는 4조건을 모두 만족한다 — 작다(한 문장), 깊다(언어 설계 철학), 실행 가능(코드로 확인 가능), 측정 가능("설명할 수 있다"는 결과 행동이 명시됨).

이 프레이밍이 작동한 증거는 회고의 깊이 차이였다. 단순히 "챕터 몇 장 읽었다"가 아니라 "val과 var의 차이를 스택/힙 메모리 관점에서 설명할 수 있게 됐다"처럼 구체화되는 경향이 나타났다. 4조건이 자기주도 학습 활동(원정대)뿐 아니라 **입학 전 단기 과정의 계획서 검토**에도 그대로 적용 가능함을 보여주는 사례다.
