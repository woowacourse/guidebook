유튜브 인터뷰 영상 45개나 한 미션 저장소의 PR 472개처럼 대용량 비정형 자료를 교육 자산으로 만들 때, **개별 문서를 한꺼번에 만들지 않고 인덱스 → 근거 → 해석 → 승격의 4단 자산 계층을 거치는** 단계적 전략. 인터뷰 챌린지 자산화 계획과 javascript-lotto PR 연구 계획 두 곳에서 같은 원칙이 정식화됐다.

핵심 판단은 "왜 바로 개별 문서를 만들지 않는가"다. 자동 자막·HTML 파싱은 품질 편차가 있어 먼저 원본 수집·정규화가 끝나야 질문/답변 단위를 안정적으로 나눌 수 있고, 제목만으론 고가치 자료와 가벼운 이벤트성 자료를 구분하기 어렵기 때문이다. 그래서 먼저 인덱스 페이지를 만들고, 이후 고가치 구간부터 개별 자산으로 승격하는 편이 유지보수에 유리하다.

자산은 4계층으로 쌓인다. **인덱스 자산**(전체 링크 인벤토리, 묶음별 분류, 수집 진행 현황) → **근거 자산**(원본 자막 `.vtt`, 시간표시 포함 정리 텍스트, 수집 JSON) → **해석 자산**(핵심 질문, 답변 요약, 반복 주제 태그, 교육 철학과 연결되는 패턴) → **승격 자산**(개별 문서, 교차 패턴 문서, 교육 모델/운영 인사이트).

javascript-lotto 사례는 이 전략을 연구로 구체화했다. 2021~2026년 누적된 472개 PR은 단일 기수 미션이 아니라 "교육 담론 코퍼스"에 가까우므로, 1차 실험을 "좋은 PR 몇 개 읽기"가 아니라 **전량 메타데이터 수집 + 코호트별(연도별 10건) 심층 표본 분석**으로 설계했다. 표본부터 시작하는 이유는 472개 전수 수집은 가능하지만 먼저 "어떤 패턴이 유의미한지" 확인해야 낭비가 적기 때문이다. 분석 축은 반복 피드백 패턴, 코칭 방식(질문형/힌트형/직접 수정 유도형/개념 설명형), 학습자 반응, 단계별 차이, 승격 가능성으로 나뉜다.

최종 승격 기준이 단호하다 — 서로 다른 코호트에서 반복되고, 실제 인용으로 뒷받침되며, 단계/코칭 차이를 설명하고, 크루·리뷰어·교육자 중 최소 두 독자군에게 유용하며, 다른 미션 저장소에도 재사용 가능한 관찰만 남긴다. 이는 [[parallel-collect-then-synthesize]](수집은 병렬, 분석은 단일)의 운영 골격과 우테코 연구 사이클의 승격 루브릭을 비정형 자료에 적용한 형태다. [[verbatim-conversation-archive]](포수타 3층 아카이브)도 같은 "원본 안정화 → 고가치 구간 승격" 철학을 공유한다.
